요구와 변경 내용

인사 담당자 요청으로 퇴직자 외 대상도 삭제할 수 있도록 PA0000 현재 유효 행 조회와 STAT2=0 제한을 제거했습니다. 사용하지 않는 인사상태 변수도 제거하고 화면 제목·사번 안내·확인창을 변경했습니다.

한 명씩 처리, 정산월 → 정산일 연결, 8050, 월마감, AWREF, 레코드 키 검사, 잠금 후 재조회와 삭제·커밋·롤백 흐름은 유지했습니다. 새 FORM이나 신규 처리 경로를 추가하지 않았습니다.

이 방의 최초 요청은 기존 로컬 개발안을 대화창에 제공하는 것이었습니다. 신규 프로그램 최초 작성 자체가 이 방에서 수행됐다고 해석하지 마세요. 최초 제공본 전체를 신규 REPORT 학습 자료로 함께 보존합니다.

첨부 참고 HTML은 다른 주제인 소급 상세 분리 보고서입니다. 형식 참고자료로만 별도 보관합니다.
