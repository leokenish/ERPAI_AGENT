추출 결과를 확인하세요

Windows 탐색기에서 ZIP을 새 폴더에 압축 해제한 뒤 선택하세요. 파일은 브라우저 안에서만 읽습니다. 서버 전송이나 원본 파일 변경은 없습니다.

1. 압축을 푼 폴더 선택

선택한 폴더 바로 아래에 manifest.xml이 있어야 합니다. 브라우저의 ‘업로드’ 표시는 폴더 읽기 허용을 뜻하며 이 도구는 네트워크 요청을 하지 않습니다.

폴더를 선택해 주세요.

2. 점검 결과

파일 무결성과 SAP 추출 상태를 따로 표시합니다. 파일이 원본과 같아도 추출 오류나 미지원 객체가 남을 수 있습니다. SAP 정의의 완전성·문법·업무 로직을 검사하는 기능은 아닙니다.

아직 실행하지 않았습니다.
점검 범위와 제한

대상은 DEVHUB-EXPORT 0.1 및 0.2 형식입니다. 소스 본문은 요약에 포함하지 않습니다. CRC32는 전송 오류 확인용이며 변조나 권한을 입증하지 않습니다. 원본 사본과 manifest가 함께 바뀌면 이 도구로 진위를 판별할 수 없습니다.

0.2 형식은 파일별 CHECK_MODE를 따릅니다. LF_UTF8은 줄바꿈을 LF로 맞추고 RAW는 바이트 그대로 비교합니다. MIME·BSP 레이아웃은 RAW입니다. 0.1 형식은 기존 ABAP/XML/MD 줄바꿈 비교를 유지합니다. 원본 사본의 CRC32는 원래 바이트를 기준으로 확인합니다. SHA-256 사용 가능 시 현재 내용의 해시도 계산하지만 화면에는 파일 본문을 표시하지 않습니다.

파일당 16 MiB, 폴더 전체 512 MiB, 선택 파일 50,000개까지 점검합니다. 첫 추출 결과에서는 변경 파일 0건이 기대됩니다. 수정 ZIP 생성·Git 갱신·SAP 가져오기는 이 버전에 포함되지 않습니다.
