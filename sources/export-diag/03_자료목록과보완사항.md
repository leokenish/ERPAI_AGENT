## F. 통합 담당자에게 전달할 원칙

1. 네 주요 MD는 현재 기준의 교육 추출본이다. `references/`는 역사·근거를 보존한 원본 사본이며 모든 문장이 현행 지침인 것은 아니다.
2. 현행 결정 → 실제 최신 소스/해당 버전 실행 증거 → 이 추출본 → 과거 요약 순으로 대조한다. 자료 종류가 다르면 우선순위만으로 원인·운영 성공을 확정하지 않는다.
3. 파일 경로·공백·대소문자는 원본 계약의 일부다. 포털 URL로 변환할 때 상대 링크를 다시 검사한다.
4. 실제 화면·실제 결과·합성 설명 그림·가상 실습을 눈에 띄게 구별한다.
5. 이 ZIP에는 실제 개발 패키지 전체가 없고 원래 ZHR5 지식 키트 전체도 없다. 다른 프로젝트 ZIP과 병합할 때 최상위 폴더를 유지한다.
6. 자료 추출 작업에서 웹사이트 제작·서버 설치·GitHub push·SAP 접속/변경은 수행하지 않았다.
