## 연결 장부 작성 방법
문서에 적힌 이름을 정확히 검색하고, 발견했을 때만 실제 경로/commit/추출일을 기록한다. 소유권은 manifest/catalog에 실제로 나타난 값을 쓴다.
예: `ZHR_52TM_CW_CAL_AND_DAEH → [실제로 찾은 함수 본문 경로] → 어떤 입력을 읽고 어떤 출력을 만드는지 → 호출처 → 규정/운영 근거 → 남은 분기`.
초기 2026-09-22 지식 묶음에는 실제 ABAP가 없어 후보로만 작성했다. 이후 실제 소스 대조와 최신 추출본 범위는 위 안내 및 날짜별 절을 따른다.

카톡의 `BS01`, `N1`, `F`, `IAM`은 별칭/코드/기능명의 문서상 설명이며 DDIC 정의 확인과 구분한다.
표준/외부 패키지의 PA2010 등을 참조한다고 해서 그 원본을 자동 추출하지 않는다. 기존 export 범위 안에서 읽고 없는 부분을 의존성으로 표시한다.
