# 협의 이력 검색 안내

아래 긴 노트를 처음부터 전부 읽기보다, 질문의 객체명·업무 용어·기준일로 먼저 검색한다. 해당 사안의 후속 정정/롤백을 함께 읽는다.

| 주제 | 우선 문서 | 검색어 |
|---|---|---|
| 초기 대휴·시차가산·일별 리포트 | [SRC-09](SRC-09.md) | `대휴`, `시차`, `최대근로`, `2022` |

| PA2010 삭제 범위와 반복 누락 | [SRC-07 전반](SRC-07-early.md), [후반](SRC-07-late-SRC-08.md) | `PA2010`, `누락`, `정산 순서` |
| 선택 누적표시·소정 미충족 오해·가산 롤백 | [업무 해석](../processes/selective-cumulative-display.md), [SRC-07 후반](SRC-07-late-SRC-08.md) | `20241015`, `20241028`, `가산`, `누적`, `소정`, `대휴` |
|208시간·간주·가산시간 | [SRC-07 전반](SRC-07-early.md), [후반](SRC-07-late-SRC-08.md), [SRC-09](SRC-09.md) | `208`, `가산`, `재난` |
| 휴일→휴일의 대휴·정산 | [SRC-07 전반](SRC-07-early.md), [후반/SRC-08](SRC-07-late-SRC-08.md) | `휴휴`, `휴일-휴일`, `4.5`, `재정렬` |
| 근로시간·익휴·52시간 | [SRC-07 후반](SRC-07-late-SRC-08.md), [SRC-10 후반](SRC-10-late.md) | `52`, `익휴`, `스케줄`, `퇴출` |

예를 들어 저장소 루트에서 `rg -n 'tdcost|시차실비' knowledge/feedback`로 위치를 찾고, 결과가 가리키는 문단과 후속 문단을 읽는다. 검색어가 없으면 원문 등록부에서 범위를 넓힌다.
여기서의 날짜는 대화 날짜이며 적용 근무일·정산월·시행일과 다를 수 있다.
