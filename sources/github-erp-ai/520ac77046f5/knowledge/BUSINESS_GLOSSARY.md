# 업무 용어집

용어를 같은 뜻으로 섞지 않기 위한 사전이다. 구체적인 적용은 출처·대상·시점을 확인한다.

|---|---|---|
| 소정근로시간 | 해당 정산기간에 기본적으로 제공할 시간 | 선택 매뉴얼의160시간 출발점과 휴가/공휴일 감소. SRC-02 p.4 |
| 최대근로시간 | 선택근무 매뉴얼의 노사합의 상한 | 법정최대라는 화면 항목과 분리. SRC-02 p.4 |
| 실근로시간 | 실제 근무시간을 가리키는 개념. 휴게·일자별 필드 산식은 해당 업무에서 확인 | 선택근로 화면의 가산 포함 누적표시와 동일시하지 않음. SRC-02 pp.5,8,14; SRC-15 |
