# 근로시간 사용자 FAQ — 정리와 오류 표시

## FAQ별 내용

| 원문 질문 | 정리 | 근거/상태 |
|---|---|---|
| 교대근무자의 반차 | 주간09~18 근무에서 사용하는 경우를 설명. 공휴일 주간 반차로 특근수당이 계산되지 않는 사례는 HR 실적 입력 후 사용자 결재 흐름 | SRC-06 L2–15, 날짜 미상 |
| 시간외 계좌 변경 | ESS 통상근무 메뉴의 계좌(급여,시간외) 변경신청에서 시간외 계좌 변경 | SRC-06 L17–21 |
| 출장일 선택근로 입력 | 국내·해외출장이라도 선택근무 실적 입력, 이동시간 제외. 간주 등록이 있으면 추가 입력 불필요라는 설명 | SRC-06 L23–28; 출장 유형/간주 여부 확인 필요 |
| 선택근무 신청/제외 | 부서 공문·M1 이상 결재, 월요일 시작~4주 일요일 종료. 원칙 전주 신청, 수요일 결재/지연시 담당자 협의 금요일 안내 | SRC-06 L30–38 |
| 기간 중 간부 보임 | 해당 기간 종료까지 평일09~18만 입력, 휴일대휴 등은 HR 문의로 안내 | SRC-06 L36–38; 현재 적용 확인 필요 |
| 반차 사용 후 시간외 | 원문은 4시간을 넘는 연장실비 설명과09~20/휴게1시간 예시를 함께 제시 | SRC-06 L40–52, 아래 오류 후보 |

## 그대로 정답으로 쓰면 안 되는 부분
1. 반차 예시는 “4시간 초과부터”라는 설명과 “2시간, 8,400×2=16,800”이라는 계산이 함께 있어 전제가 빠졌거나 상충한다. 근무형태·반차 구간·소정근로·휴게·해당 시점 단가를 확인해야 한다. 이 예시만으로 자동 계산 공식을 만들지 않는다. [SRC-06 L40–52]
2. 마지막에 선택근무 신청 설명이 다시 붙어 있다. 반차 질문의 직접 답으로 사용하지 않는다. [SRC-06 L53–56]
3. 8,400원은 작성일을 알 수 없는 예시 단가다. 현재 시간외 단가로 쓰지 않는다.

전문 63행을 검토했다. 개인정보·사례 직원 식별자는 이 정리본에 옮기지 않았다.

## 후속 확인: 통상·시차 반차 입력

SRC-14(2026-10-01)에서 원래 출근시각부터 전체 구간을 입력하고 반차·지참·조퇴를 반영하는 처리 방식을 확인했다. 위 반차 예시의 입력 구간은 실제 근무만을 뜻한다고 해석하지 않는다. 다만 과거 예시 금액의 모든 전제가 해소된 것은 아니다. [현재 입력 기준](../processes/overtime-start-time.md).
