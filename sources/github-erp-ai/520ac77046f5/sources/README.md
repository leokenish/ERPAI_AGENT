# 원문 보관

`original/`의 SRC-01~11은 업로드 파일의 바이트를 그대로 보존한다. 원래 파일명과 SHA-256은 `../docs/SOURCE_REGISTER.md`에 있다.

`text/`의 TXT 7개는 BOM을 제거한 검색용 사본이며 원문 행 순서를 유지한다. 인용은 이 사본 또는 원문 기준이다.

원문을 고쳐서 AI 정리본의 오류를 맞추지 않는다. 새 판본은 새 출처 ID/버전으로 등록한다.

원문에는 직원 정보가 포함될 수 있어 기본 Git 제외 대상이다. Markdown 정리본만 공유받은 팀원은 정확한 원문 확인이 필요할 때 허용된 보관소에서 원문을 확보해야 한다.
