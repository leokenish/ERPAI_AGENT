자료를 Markdown으로 정리하는 것은 모델을 재학습하는 작업이 아니다. 에이전트가 질문할 때 필요한 근거를 찾아 읽도록 구성하는 작업이다.
`AGENTS.md`는 저장소의 공통 작업 규칙, `SKILL.md`는 특정 작업 절차, `knowledge/`는 참고 지식이다. 일반 MD는 존재만으로 매번 자동 로드되지 않는다.

## 다른 패키지 에이전트와 연결

공통 용어·출처 형식·질의 전달 형식을 공유한다. ZFI에는 지급/전표 상태 확인, ZMM에는 구매 관련 근거 확인처럼 역할을 제한해 요청한다.
이 지식 묶음만으로 에이전트 간 자동 통신이 생기지는 않는다. 실제 협업 실행은 사용 중인 Codex 작업/별도 오케스트레이터에서 구성한다.

요청 예: 기준월, 익명 사례 ID, 확인할 업무 질문, HR에서 확인한 사실과 근거, FI에서 확인할 전표 상태, 미확인 사항을 전달한다.
원본 직원 명단을 불필요하게 패키지 간 복사하지 않는다. GitHub는 지식·절차·변경 이력 공유에 사용하며, 업무 승인 시스템을 대체하지 않는다.
