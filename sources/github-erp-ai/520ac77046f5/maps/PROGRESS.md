# 전체 업무 진행 상태

2026-10-08 추가 분석: [선택근무 특별연장 입력·정산](topics/special-extension.md#선택근무%20특별연장%20입력과%20정산%20분석%202026-10-08). PC 입력과 ABAP/XML 20개 파일의 지정 구간을 대조하여 활성·동의·저장·상신·승인, 입력 한도, 총시간·연장·가산·대휴 영향과 과거 분기를 확인했다. 아래 초기 전체 범위표를 전면 재검토한 것은 아니며, 현재 운영 승인·모바일 전체·모든 시간 조합은 미검증이다. [확인 구간·검증 장부](audit/selective-special-extension-review.json).

[전체 목차](INDEX.md)
기준일: 2026-10-07. 업무별로 아래 순서의 대표 단계·근거 구간을 검토했다. **23개 업무군의 단계 지도 작성 완료**와 **전체 파일/전체 분기 의미 분석 완료**는 다르다. 파일별 판정은 COVERAGE를 따른다. 새 소스 사실을 현행 정책·운영 반영 승인으로 승격하지 않는다.
