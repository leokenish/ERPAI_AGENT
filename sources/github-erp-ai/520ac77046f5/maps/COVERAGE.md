# 전체 파일 대조와 분석 범위

[전체 목차](INDEX.md) · [업무별 진행 상태](PROGRESS.md) · [검증 결과](verification.md)

기준일은 2026-10-07이다. 현재 저장소에서 **발견한 업무를 모두 등록**했고, 각 업무의 대표 단계·소스 연결을 작성했다. 모든 파일의 목록화·구문 색인과 모든 업무 규칙/분기의 의미 분석은 다르다. 출처 원문이 없으면 기존 정리본의 과거 검토 범위를 이번 직접 검토로 세지 않는다.

## 상태 판정

| 상태 | 의미 | 완료로 보지 않는 것 |
|---|---|---|
| 분석 완료 | 파일 본문 전체의 명시한 정적 분석 범위를 읽었거나, 이번에 작성한 탐색 문서·검증 산출물 | 외부 함수·운영 데이터·업무 전체·SAP 실행·배포·실무 승인 |
| 후보 | 객체·정의·호출/참조를 식별했으며 일부 지정 구간을 검토했거나 자동 색인함 | 전체 코드 의미·모든 조건·직접 연결되지 않은 업무 배정 |
| 미검토 | 파일은 목록에 있으나 이번 본문/의미 검토가 없음. 지원하지 않는 객체·내용 미확인 포함 | 파일 존재를 분석 완료로 집계하는 것 |
| 업무 무관 | 이번 업무 로직 그래프의 분석 대상에서 제외: baseline 중복, 이미지·폰트·CSS, OS/Obsidian 설정 등 | 프로젝트 전체에서 쓸모없거나 삭제 가능하다는 판정 |

파일별 상태, 검토 구간, 미검토 범위, 연결된 설명 문서는 [현재 전체 파일 목록](audit/file-coverage.csv)에 기록한다. `.git` 내부만 제외한다. baseline은 보존 해시/목록에만 남기며 업무 그래프에 연결하지 않는다. 이미지·폰트의 업무 의미/화면 디자인은 분석하지 않았다. 실제 파일 목록과 객체 목록은 단위가 다르다.

## 관계의 의미와 추출 한계

| 관계 | 확인한 것 | 한계 |
|---|---|---|
| 직접 호출 | 주석을 제외한 정적 `CALL FUNCTION '이름'` | 함수 내부·권한·커밋·실행 성공 별도 |
| 웹 요청 | Layout JavaScript의 `FUNCTION_NAME` 리터럴 | AJAX dispatcher의 실제 실행·인증 구현 미추출 |
| Include | ABAP INCLUDE에 적힌 컴파일 구성 | 실행 순서/현재 실행 진입점 아님; `INCLUDE TYPE/STRUCTURE`와 구분 |
| FORM 호출 | PERFORM과 같은 함수그룹 또는 Include 문맥의 유일한 FORM 이름 연결 | ABAP 컴파일러가 아님; 매크로/동적 호출/여러 정의는 미해결 장부 |
| 타입 참조 | TYPE/LIKE/STRUCTURE, XML ROLLNAME/DOMNAME/ROWTYPE/인터페이스 타입 등 | 실제 DB 읽기/쓰기 아님; 표준 기본타입 전체 설명을 만들지 않음 |
| 데이터 조회 | SELECT 문맥의 FROM/JOIN | 동적 SQL, 매크로·외부 클래스 내부 접근 누락 가능 |
| 데이터 저장 | 추출된 DB 이름 또는 명확한 PA/ZTHR/ZWF 계열의 INSERT/MODIFY/UPDATE/DELETE | 동일명 내부 테이블 여부·경로 조건·잠금·커밋·성공 여부는 원문 문맥 확인 |
| 뷰 구성 | DDIC XML의 구성 테이블 | 외래키 강제나 실제 조인 실행을 입증하지 않음 |
| 클래스 참조 | 정적 클래스 멤버 구문 | 클래스 본문 미추출·동적 메서드 미해결 |
| 분석상 연관 | 같은 데이터의 생산자/소비자, 헤더·화면 목적에 따른 업무군 분류 | 직접 호출·자동 후속 실행·현행 정책 근거가 아님 |

자동 분석기는 완전한 ABAP/HTML/JavaScript 파서가 아니다. 주석을 배제하고 명시된 패턴만 색인한다. 구문 위치 일치 검사와 업무 의미 수동 검토를 구분한다. 새로운 코드 판본에서는 구문·호출 문맥을 다시 검토해야 한다.

## 시점과 원본 보존

manifest의 `COMPLETENESS=PARTIAL`, `CAPABILITY=ANALYSIS_ONLY`, `DEPENDENCY_POLICY=REFERENCE_ONLY_EXTERNAL`을 따른다. 2026-09-21 추출일은 기존 지식의 기록이며 현재 run 로그가 없어 이번에 재검증하지 못했다. 2026-10-07은 이번 분석일이다.

현재 기준은 기존 단가·직군·입력시각 정정 문서의 적용범위를 따르고, 과거 카톡·2022 매뉴얼·코드 주석을 현재 승인 기준으로 바꾸지 않았다. 기존 knowledge의 “이 묶음에는 소스 없음”은 작성 당시 지식 묶음의 범위다. 이번에는 로컬 exports의 실제 파일을 근거로 연결했다.

이번 변경 대상은 `maps`다. `SKILL.md`, `knowledge`, `harness`, `exports`, 업무 원문, 기존 실행기는 유지한다. 원본 보존·파일 누락·목차 도달 가능성·근거 행 대조 결과는 [최종 검사 장부](audit/scope-validation.json)와 [검증 문서](verification.md)에서 확인한다.
