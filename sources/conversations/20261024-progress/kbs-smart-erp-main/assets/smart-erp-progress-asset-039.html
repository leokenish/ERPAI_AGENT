KBS Smart ERP · S-Core Dream 적용 v9

2026-10-23 · 기존 v8 배경과 UI 구성에 에스코어 드림 웹폰트를 적용했습니다.

적용 내용

상단 내비게이션, 좌측 메뉴 트리·검색·결재현황, 주요 업무 지표, 업무공지·알림게시판·관련서식에 S-Core Dream을 적용했습니다. 본문은 Regular 400, 업무 지표 숫자는 Medium 500, 메뉴 분류·패널 제목은 Bold 600을 사용합니다. 4K 배경 PNG는 v8과 바이트 단위로 같으며 기존 배치 값·메뉴 구조·이벤트·URL·조회 로직을 유지했습니다.

각 iframe에서 글꼴을 사용할 수 있도록 기존 공통 헤더가 불러오는 common.css에 이름이 지정된 @font-face 정의만 추가했습니다. 기존 공통 CSS 바이트는 그대로이고 다른 업무 화면에 글꼴을 강제하는 전역 선택자는 추가하지 않았습니다. S-Core Dream 선택은 메인화면 전용 스타일에 한정됩니다. 공통 CSS를 사용하지 않는 home_list.kbs에는 Regular 글꼴 정의를 별도로 포함했습니다.

OTF를 변환·서브셋·수정하지 않고 원본 바이트로 포함했습니다. 외부 CDN이나 사용자 PC 폰트 설치가 필요하지 않습니다. 로딩 중에는 시스템 폰트를 표시하는 font-display:swap을 사용합니다. 미리보기는 같은 폰트 CSS를 하나의 Blob으로 공유해 중복 데이터를 줄였습니다. 운영 화면은 기존 common.css URL과 브라우저 캐시를 사용합니다.

출처와 라이선스

에스코어 공식 글꼴나눔 안내에서 개인·기업 무료 사용과 재배포 조건을 확인했습니다. 공식 다운로드 서버가 502/503을 반환하여 재배포 페이지의 OTF 묶음을 확보했습니다. 동봉 라이선스와 폰트 내부의 제작사·명칭을 확인했으며 다운로드 ZIP과 실제 포함 OTF의 해시가 일치합니다. 공식 서버의 최신 배포 파일과 직접 해시 대조는 하지 못했습니다.

Regular 파일 내부 weight는 200으로 기록되어 있으나 글꼴 이름이 S-Core Dream 4 Regular이므로 CSS에서는 400으로 지정했습니다. 파일 내부 값을 고치지 않았습니다. 각 적용 글꼴은 한글 완성형 11,172자를 포함하며, 미지원 문자는 시스템 폰트를 사용합니다. 원본 9종 묶음·적용 3종·저작권 안내·파일 해시는 assets/fonts/s-core-dream에 포함했습니다.

수행한 검증

상단·홈·트리·결재 iframe의 실제 FontFaceSet 로딩 상태, 각 요소의 계산된 글꼴과 굵기를 확인했습니다. 1366×768, 1900×932, 1920×1080, 3840×2160에서 바깥 넘침·배경 빈틈·게시판 겹침이 없었습니다. 1093×614의 좁은 표시 영역에서는 게시판이 세로로 배치되고 내부 스크롤이 유지됩니다. 메뉴 검색과 업무 이동 URL, 결재대기 이동과 홈 복귀를 확인했습니다. 실제 업무 문서는 샘플 대체 화면입니다.

서버 템플릿 script·print·include와 클라이언트 JavaScript는 v8과 동일하며, 변경 Layout의 스타일 밖 마크업도 동일합니다. JavaScript 문법 검사와 4개 반영 ZIP의 전체 경로·내용·CRC 검사를 통과했습니다. SAP 서버의 인증·권한·실제 RFC·저장·활성화, 실제 Windows Firefox/IE 모드와 모니터·OS 배율은 검증하지 않았습니다. 운영 서버에는 반영하지 않았습니다.

반영·복구

현재 서버 export로 백업을 확보한 뒤 apply/의 4개 앱별 ZIP을 기존 DIAG 절차로 개발 시스템에서 먼저 비교·진단합니다. 이미 v8이면 이번 차이는 위 6개 파일이며, 최초 export 기준 누적 변경은 7개입니다. 공통 CSS를 포함해 같은 배포 단위로 반영하고 캐시를 갱신합니다. 최초 원본 복구는 최신 서버 export를 입력으로 restore_from_fresh_exports.py를 실행합니다. 현재 파일 해시와 새 baseline을 검사한 뒤 원본 내용 복구 후보 ZIP을 만듭니다. v8로만 돌아가려면 최신 export 기준으로 이번 6개 파일의 v8 내용을 병합하세요.

미연계 지표·알림 게시판 구분값과 기존 외부 의존성은 이전 누적 보고서와 같습니다. 해당 보고서의 ‘common.css 미수정/누적 6개 파일’ 설명은 v7 기록이며, 현재 v9의 변경 범위는 본 보고서와 changes.json을 따릅니다.
