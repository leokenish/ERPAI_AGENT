# WebGUI V429 — 중첩 스크롤·보조창 하단 아이콘 수정

재발행일: 2026-10-22 · 적용 기준: V428 · UI 4.2.6 · 신규 결재 1.4.5 유지

## 2026-10-22 ZIP 재발행

기존 적용 ZIP에 원복용 GUI.JS의 미완성 로컬 헤더와 누락된 ZIP 종료 정보가 확인되어 다시 생성했습니다. `Z_ITS_WEBASSET_APPLY`의 `Manifest byte count and ZIP content disagree` 오류에 대응한 패키지 수정입니다. 파일명은 같으므로 **이번에 제공한 링크에서 다시 다운로드한 ZIP**을 사용하세요.

ZIP을 메모리에서 완성한 후 파일로 한 번에 기록하도록 변경했습니다. 최종 파일을 별도 프로세스에서 다시 열어 로컬 헤더·중앙 디렉터리·종료 정보·압축 데이터·CRC·매니페스트 바이트 수와 SHA-256을 대조했습니다. 적용용 JS/CSS와 원복용 JS/CSS의 바이트는 이전 V429 소스와 같습니다. UI 코드는 4.2.6, 결재 코드는 1.4.5입니다. ABAP의 바이트 수 검증을 해제하거나 완화할 필요가 없습니다.

## 적용 파일

`SE80_WebGUI_V429_Scroll_ButtonFix_2files.zip`은 **V428 적용 환경용 증분 적용본**입니다. 신규 설치용 전체 패키지가 아닙니다. ZIP의 `apply/` 아래 두 파일을 기존 SAP MIME 객체에 덮어씁니다.

| 서비스 | 테마 | MIME 이름 | 변경 내용 |
|---|---|---|---|
| WEBGUI | SL | SCRIPTS/GUI.JS | 본문 영역 크기·스크롤 담당 영역 조정, 아이콘 축소 반복 계산 제거 |
| WEBGUI | SL | STYLE/GUI_BUTTON.CSS | 아이콘만 있는 일반 흐름 버튼의 최소 30×30 크기와 가운데 정렬 |

ABAP, ZWGUI_APPR_CFG, HTML 템플릿을 변경하지 않습니다. `GUI.JS` 안의 신규 결재 1.4.5 모듈과 기존 SVG 원형 데이터는 V428과 바이트 단위로 같습니다. V426.2 다운로드 관련 `ITSDOC.JS`, `GUI_ITSDOC.html`은 이번 적용 대상에 포함하지 않습니다.

## 수정 내용

### 1. 중첩 스크롤

- 제목·도구 모음·하단 버튼 행을 제외한 본문 높이를 계산하고, `webguiContainer → webguiUserArea → webguiDynpro`의 중복된 바깥 스크롤을 정리합니다.
- 실제 보조창의 `.WebguiPopupBorder`도 내용 측정에 포함합니다. iframe 테두리를 포함한 크기로 부모 화면 안에 맞춥니다.
- 달력은 날짜 선택부를 남기고 월/일 목록 영역만 스크롤합니다. V428의 자동 확장 방지와 수동 창 크기 지정 동작을 유지합니다.
- 검색도움말은 검색조건, 결과, 도구 모음 높이를 구분합니다. 조건이 길면 조건 영역을, 정적 결과가 길면 결과 영역을 스크롤합니다. 접기/펼치기 후에도 다시 맞춥니다.
- 전용 전체 화면 ALV는 해당 그리드의 기존 크기 조정 함수를 사용합니다. 일반적인 긴 입력화면은 본문 하나에서 끝까지 스크롤할 수 있습니다.
- SAP에서 다음 행을 불러오는 **네이티브 스크롤바와 페이지 범위는 유지**합니다. 서버에 없는 행을 표시한 것처럼 처리하거나, 마지막 행을 잘라 스크롤바만 감추지 않습니다. 고정된 서버 페이지 전체가 작은 창에 들어가지 않는 경우에는 접근을 위한 본문 스크롤이 함께 남을 수 있습니다.
- 클래식 LIST 및 신규 결재 수집 화면은 이번 스크롤 조정에서 제외합니다.

### 2. 하단 아이콘 버튼이 가늘어지는 현상

원인은 SVG 매핑 누락이 아니라 **현재 버튼 폭에서 여백을 빼 아이콘 크기로 다시 사용하는 반복 계산**이었습니다. 자동 폭 버튼은 아이콘을 따라 줄고, 다음 실행에서 다시 줄어 최종적으로 1px 아이콘·약 3px 버튼이 됩니다. SVG 매핑 유무와 관계없이 재현됐습니다.

- 일반 흐름에 배치된 아이콘 전용 버튼은 최소 30×30, 아이콘은 18×18로 유지합니다.
- 절대 위치와 폭을 명시한 기존 Dynpro 버튼은 지정된 폭을 유지하고 그 안에서 가운데 정렬합니다.
- 미매핑 아이콘은 원본 이미지로 표시하며, 원래 클릭 명령·비활성 상태·툴팁을 유지합니다.
- 기존 1,247개 SVG 원형 데이터와 아이콘 디자인은 변경하지 않습니다.

## 적용 순서

1. 업무 입력값을 저장하고 현재 운영 중인 위 두 MIME 파일을 별도로 백업합니다.
2. **새로 다운로드한 적용 ZIP**을 `Z_ITS_WEBASSET_APPLY`에 넣고 기존 절차로 검토합니다. `WEBGUI / SL`의 `SCRIPTS/GUI.JS`, `STYLE/GUI_BUTTON.CSS` 두 행을 확인합니다. 기준 비교가 다르면 그 차이를 확인하고 진행합니다.
3. 기존 절차대로 저장·게시합니다. JS와 CSS **두 파일을 함께** 반영합니다. 수동 반영 시에는 SE80의 기존 두 MIME 객체에 `apply/services/...` 아래 파일을 업로드합니다.
4. 열려 있던 보조창을 닫고 새 WebGUI 세션에서 강력 새로고침한 뒤 확인합니다. 이전 리소스가 남으면 해당 WebGUI 사이트 캐시를 지우고 다시 엽니다.
5. 콘솔에서 다음으로 확인합니다. 읽기 전용 진단이며 업무 입력값은 반환하지 않습니다.

```javascript
kbsWebguiV2.version                 // "4.2.6"
kbsWebguiV2.inspectUI().patch       // "4.2.6"
kbsWebguiV2.inspectUI().css.button  // "4.2.6"
kbsWebguiV2.inspectUI().scrollLayout
kbsWguiApproval.version            // "1.4.5"
```

GUI_CUA·GUI_SCROLL·CALENDAR 등 변경하지 않은 파일의 진단 버전은 기존 값이 정상입니다. 모든 개별 자산 버전이 4.2.6이 되는 패키지는 아닙니다.

## 검증 범위

Chromium Chromium 153.0.8010.0에서 표준 모드와 Quirks 모드의 로컬 재현 테스트 **59개 통과**. 기존 축소 문제 재현, 100회 초기화, 버튼 정렬·명령·이미지 교체, 실제 CALENDAR/GUI_SCROLL/GUI_GRIDVIEW/SEARCHHELPCTRL 스크립트와 SAP 템플릿 구조를 사용한 크기 조정·스크롤을 확인했습니다. iframe 테두리, 작은 화면, 달력 DOM 교체, 수동 크기, 입력값 유지도 포함합니다.

실제 SAP 서버의 업무 데이터·페이지 응답·결재 처리·다운로드를 실행한 결과는 아닙니다. SYSTEM 유틸리티 중 이벤트 등록과 좌표 조회만 로컬 테스트 어댑터를 사용했습니다. 데이터 요청을 대체하거나 전송하지 않습니다. 서버가 반환하는 메뉴별 추가 HTML 구조는 적용 후 위 업무 화면에서 확인해야 합니다.

정적 검증: JS 구문, UTF-8/CRLF, 정확한 SAP MIME 키, 결재 모듈·SVG 데이터 동일성, 적용 대상 2개, ZIP 무결성 및 원복 파일 일치.

## 원복

`SE80_WebGUI_V429_Rollback_to_V428_2files.zip`의 `apply/` 아래 두 파일을 같은 객체에 반영·게시하면 V428 시점으로 돌아갑니다. GUI.JS는 UI 4.2.5/결재 1.4.5, GUI_BUTTON.CSS는 당시 CSS 4.2.0입니다. V426.2 다운로드 파일에는 영향을 주지 않습니다. 이번 패키지의 기준본과 운영 파일이 다르게 수정되어 있었다면 1단계에서 직접 백업한 파일을 사용합니다.
