- 버전: **v0.3** — 기존 `intent.md`의 `0.2-template`을 실제 프로젝트 내용으로 개정
- 작성·수정일: **2026-10-23 (Asia/Seoul)**
- 문서 상태: **이번에 생성한 검토용 초안**. 사용자 검토 및 프로젝트 출처 반영은 아직 확인하지 않음.
- 사용한 자료: 현재 대화의 사용자 요청, 관련 대화 검색 결과, 기존 네 Markdown 템플릿, `KBS_WebGUI_Consolidated_Spec_20261021.md` v1.0, V424 검토 ZIP의 README·검증 기록, V425~V429 README, V429 적용·원복·검토 ZIP의 실제 내용.

## 1. 목적과 배경

기존 SAP ECC 6.0 WebGUI의 업무 기능을 유지하면서, ERP 웹 iframe 안에서 사용자가 메뉴를 찾고 값을 입력하고 목록·결재 문서를 읽고 파일을 내려받는 과정의 장애를 해소한다. 화면을 새로 그렸다는 사실보다 **기존 업무의 의미와 조작을 유지한 채 실제 사용 가능한 상태**를 만드는 것이 목적이다.

사용자는 메뉴 드롭다운 잘림, 입력값을 가리는 서치헬프, 작거나 계속 늘어나는 달력, ALV 뒤 요소의 밀착, 불균일하거나 사라지는 아이콘 버튼, 중복 스크롤을 반복 보고했다. 신규 결재 화면에서는 비대상 메뉴의 불필요한 준비 안내, 구 화면의 순간 노출, 불용자산 문서의 `OVERLAP_MISMATCH`가 문제였다. 엑셀 다운로드에서는 Java Applet 경로와 공통 브라우저 대체가 별도 과제로 이어졌다. 최근에는 제공한 V429 ZIP 자체의 불완전성으로 적용 도구가 실행을 중단했다.

이는 각각 화면 표시, 대상 판정, 문서 수집, 파일 전달, 배포 파일의 문제다. 같은 시기에 발생했다는 이유만으로 하나의 원인으로 묶지 않는다. 특히 `unload` 경고를 모든 다운로드 실패의 확정 원인으로 보지 않는다.

## 2. 사용자와 이해관계자

| 대상 | 이 프로젝트에서 필요한 결과 | 확인 수준 |
|---|---|---|
| 프로젝트 요청자·ERP 개발/운영 담당자 | 적용할 파일과 바뀐 범위를 식별하고, 문제를 재현·수정·원복할 수 있음 | 현재 대화의 요청·실제 적용 오류 보고에서 확인 |
| 기존 ERP 업무 사용자 | 익숙한 메뉴·아이콘 의미를 유지하며 입력, 조회, 서치헬프, 다운로드 수행 | 사용자 요구에서 확인; 전체 현장 검수는 미확인 |
| 신규 결재 화면 이용자 | 등록된 화면에서 원본 문서의 본문·금액·결재란을 빠짐없이 확인하고 기존 업무 명령 사용 | 요구 및 기존 명세에서 확인 |
| SAP 자산 반영·운영 담당 역할 | 기존 객체에 정확한 증분을 반영하고 실행 버전을 확인 | 필요한 역할로 식별; 실제 담당자·승인 체계는 미확인 |

개별 사용자 수, 운영 조직의 승인 절차, 지원 브라우저 전체 목록은 확인하지 않았다.

| G-03 | 설정으로 지정한 결재 화면만 신규 화면으로 표시하고, 원문이 검증된 문서만 완성 처리 | spec.md REQ-007~008 |

## 4. 현재 유효한 핵심 결정과 이유

| 결정 | 현재 기준과 이유 | 근거·확정 구분 |
|---|---|---|

| D-03 등록 화면의 구 화면 노출 방지 | 준비 표시를 일괄 제거하는 것만으로 해결하지 않고, 등록된 대상의 첫 표시를 제어 | **사용자 확정**: 구 화면이 잠깐 나타나는 회귀에 대한 수정 요구 |
| D-04 결재 원문을 보존 | 실제 문자·숫자 차이를 무시하여 오류를 통과시키지 않음. 화면 경계에서 잘린 네이티브 선만 증거가 있을 때 복원 | 사용자 요구를 충족하기 위한 **기존 명세·구현 제약**. V427 README 근거; 세부 알고리즘을 사용자 직접 설계로 기록하지 않음 |
| D-05 공통 Applet 대체 | 개별 메뉴 ABAP 변경 대신 WebGUI 공통 JavaScript·템플릿에서 FileSaveDialog/Export 역할 대체 | **사용자 확정**: 공통 가능성 검증 후 “공통 JavaScript·템플릿 … 개발” 요청 |
| D-06 스크롤과 버튼을 함께 수정 | 내용 영역과 외곽 창의 역할을 나누고, 하단 아이콘 버튼이 가늘어지는 현상도 수정 | **사용자 확정**: 두 이슈 모두 수정 요청. 세부 크기·선택자는 구현 기준 |
| D-07 배포 파일 검증 유지 | `Manifest byte count and ZIP content disagree`에 대해 ZIP을 고쳐 재발행. 업로더의 바이트 검증은 유지 | 오류 해결 요청은 **사용자 확정**; 검증을 완화하지 않는 방법은 **현재 구현 판단**. V429 재발행 README·ABAP 계약 발췌 근거 |

기존 통합 명세의 “74개를 새 선 아이콘으로 대응”과 “최신 UI 4.2.3 / 결재 1.4.4”는 당시 이력이다. 전자는 D-01로 대체되었고 후자는 이후 릴리스로 갱신되었다. 입력값·원문·업무 명령 보존 등의 제약은 계속 유효하다.

## 5. 반드시 지킬 원칙과 경계

- 기존 SAP 명령, 폼, 활성 프레임, 팝업, 선택·취소·비활성 상태를 유지한다. 표시 개선 때문에 입력의 `name`, `value`, `maxlength`나 업무 의미를 바꾸지 않는다.
- 기존 환경과 객체를 사용한다. 최신 패치는 전체 설치본이 아니므로 현재 서버의 파일과 기준본을 비교하고, 별도 사용자 수정이 있으면 이를 보존한다.
- 신규 결재 대상 TCODE를 JavaScript 목록으로 고정하지 않는다. 비대상의 결재 처리 제외와 대상 판별에 필요한 설정 조회는 구분한다.
- 마지막 행·필드·버튼을 잘라 내거나 실제 SAP 페이지 이동용 스크롤을 숨기는 것으로 화면 문제를 해결하지 않는다.
- 결재 수집에서 원문 누락·충돌을 빈칸이나 임의 값으로 덮지 않는다. 승인·반려 같은 업무 명령을 자동 재전송하지 않는다.
- 다운로드는 서버가 만든 원본 바이트를 유지한다. 브라우저 다운로드 클릭을 OS 저장 완료로 간주하지 않는다. 지원하지 않는 Applet 작업을 성공으로 위장하지 않는다.
- 배포물에는 사용자 업무 본문·세션 값·캡처·영상이 섞이지 않게 한다. 검토용 자료와 직접 적용용 ZIP을 구분한다.
- 구현, 로컬 시험, 사용자 확인, 실제 반영은 각각 근거가 있는 범위까지만 기록한다.

## 6. 포함 범위와 제외 범위

**포함:** WEBGUI 공통 UI 자산, 원형 유지 SVG, 입력·ALV·달력·보조창, 설정 기반 신규 결재의 진입·본문 수집·기존 명령 연동, 공통 FileSaveDialog/Export 대체, 관련 종료 처리, 적용·원복 패키징 및 진단·인계 자료.

**명시적으로 현재 목표에 포함하지 않음:** 의미가 달라지는 전면 아이콘 재설계, 메뉴마다 업무 ABAP을 고쳐 다운로드 경로를 만드는 방식, 임의 TCODE 예외, 오류·인증·무결성 검사를 무조건 해제하는 방식, DAT를 XLSX로 바꾸는 기능, 모든 Java Applet 모드의 대체, 새 시스템 전체 재구축.

부모 ERP `layout.htm`은 iframe 통합 확인 대상이다. 다른 대화에서 언급된 포털 메인 화면 디자인, `ERP_DIAG` 기능 개발, 별도 MCP/인증 연동, `KBS_WORK_TIME_LINE`은 이 문서의 완료 범위가 아니다. 공통 도구 `Z_ITS_WEBASSET_APPLY`는 배포 계약을 참조하지만 그 도구의 전체 개발 상태를 본 프로젝트의 성과로 합치지 않는다.

## 7. 문서 연결 및 남은 목적상의 질문

- 무엇을 만족해야 하는가: **spec.md §3 요구사항**, §4 상세 계약.
- 어디까지 했고 무엇부터 할 것인가: **plan.md §4 진행 상태**, §7 다음 작업.
- 판단 근거와 사용자 가치: **insight.md §2~§6 통찰**.

핵심 방향을 다시 결정해야 할 질문은 현재 없다. 남은 것은 주로 검증 범위다. 운영 반영 대상 브라우저·메뉴 목록과 최종 수용 책임은 아직 확인하지 못했다. 이는 원형 유지·설정 기반 결재·공통 다운로드라는 확정 방향을 보류하는 이유가 아니다.

## 8. 주요 변경 요약과 미확인 사항

- `0.2-template`의 빈 양식을 실제 프로젝트의 목적·결정·경계로 개정했다.
- 이전 v1.0 통합 명세의 유효 제약은 유지하고, 이후 아이콘 결정과 V429까지의 범위를 반영했다.
- 최신 재발행 ZIP의 SAP 적용 성공, 결재 1.4.5 현장 해결, 다운로드 전체 메뉴 적용은 **미확인**이다.
- 이 문서 개정은 **프로젝트 출처 갱신이나 SAP 반영 완료를 의미하지 않는다**.
