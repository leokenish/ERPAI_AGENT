## 1. 이번 결과

누락된 과거 리팩토링 답변은 대화 조회를 다시 시도했지만 실제 본문을 반환받지 못했다. **SYSTEMGUI·화살표 오류·Chrome v3·추가 구조 제안의 새 전문 확보는 0개**다. 검색 결과의 ‘전문이 있다’는 문구를 전문 자체로 간주하지 않았다.

현재 대화에 직접 보이는 이전 교육자료 추출 작업의 **진행 안내 4개·최종 답변 1개**는 새로 포함했다. 이로써 기존 마지막 요청 wg-m050과 후속 상태 문의 wg-m051에 응답이 연결된다. 과거 리팩토링 누락을 해결한 수치와 구분한다.

## 4. 확보 경로와 한계

이전 ZIP을 이름으로 검색하여 통합 프로젝트 폴더의 복사본을 다시 내려받았다. SHA-256은 기존 생성본과 일치했다. ZIP의 JSON·README·학습 가이드·기존 첨부를 읽고 대조했다. 6회 대화 검색/재조회는 9월 SYSTEMGUI·커서 오류·v3·구조 제안의 요약과 일부 시각 단서를 반환했다. 특정 메시지 본문을 상세 읽기할 수 있는 실제 참조는 반환되지 않았다.

현재 도구 목록에 없는 대화 export 기능을 사용했다고 주장하지 않는다. 검색 c0/c1 표시는 메시지 ID가 아니며 임의 API/URL로 변환하지 않았다. 다른 대화방 전체·생략된 초기 대화·모든 진행 메시지를 읽었다고 가정하지 않는다. 시각 단서는 원문 동일성 확인 전까지 기존 timestamp에 넣지 않는다.

이번 추출은 이전 작업의 최종 답변 wg-m056까지다. 현재 보완 요청과 진행 안내는 재귀적으로 포함하지 않았다. 이전 작업 중 반복 제출이나 먼저 나온 안내의 전문은 직접 다시 확보되지 않은 범위로 남긴다. 길이 때문에 확보된 메시지 중간을 생략하지 않았다.

## 5. 첨부와 보존

기존 포함 첨부 46개와 모든 기존 asset ID/path를 보존했다. 초기 WEBGUI·스크롤·SYSTEMGUI·커서·v3 코드와 보고서·증빙을 포함한다. 새로 추가한 3개는 이전 ZIP 원본, 조회 기록, 요청–응답 색인이다. 파일을 갖고 있다는 사실은 당시 AI 답변을 갖고 있다는 사실과 다르다.

과거 읽기용 전사 `assets/source_notes/conversation_transcript.md`는 41개 발화의 원형으로 남아 있다. 현재 47개는 JSON과 AI_RESPONSES_FULL.md에서 읽는다. 기존 문서의 이전 집계는 당시 기록이며 새 집계는 이 README를 따른다. 코드와 기존 첨부 바이트는 수정하지 않았다.

원문에 있는 과거 sandbox 링크는 역사적 링크다. 포털에서는 asset_ids→assets.path의 상대 경로로 다운로드를 연결한다. path의 기준은 이 최상위 폴더다. 프로젝트·주제를 포함한 최상위 폴더로 다른 프로젝트 ZIP과 충돌을 피한다.
