## 기준 파일과 파일 조회

정확한 이전 ZIP 이름으로 검색하여 통합 프로젝트 폴더의 복사본을 다시 내려받았다. SHA-256은 `ba125fa3899db72a2e3820817bf846bdeba665b2451acdfa65624b9600d6c125`이며 이전 생성본과 동일하다. JSON 41개 발화, README, 학습 가이드와 현재 보이는 대화를 대조했다.

추가 파일 검색어는 `SYSTEMGUI "답변" "원문"`, `"ITS_Chrome_v3" "대화"`, `"conversation-data" "webgui"`다. 관련 결과는 기존 conversation-data와 보고서·요약에 해당했고 독립 원문 대화 export는 찾지 못했다. 관련 없는 HR·다른 프로젝트 결과는 근거로 채택하지 않았다. 검색 결과 제목/스니펫만으로 파일 본문을 확보했다고 보지 않는다.

## 전문으로 채택하지 않은 이유

반환된 ‘전문이 있음’은 전문 자체가 아니다. 검색 문장은 항목을 압축한 설명체이고 원래 표·코드·정확한 링크·첫/끝 문장이 없다. 같은 파일명과 검증 수치가 있다는 이유로 보고서 본문을 당시 답변으로 교체하지 않았다. 검색 결과의 관련 없는 대화와 현재 검색 요청 자체가 재검색된 결과도 제외했다.

현재 제공된 도구 목록에서 개인 대화 검색 외에 특정 ChatGPT 메시지 ID로 본문을 fetch/read하는 기능은 확인되지 않았다. 반환된 c0/c1 표시는 조회별 검색 표식이지 직접 조회 가능한 플랫폼 메시지 ID가 아니다. 이를 임의의 URL이나 내부 API로 바꾸지 않았다. 따라서 네 누락 구간은 missing으로 유지한다.
