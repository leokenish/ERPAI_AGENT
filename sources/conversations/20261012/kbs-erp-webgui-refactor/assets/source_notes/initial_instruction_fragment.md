【10. CSS와 JavaScript 연계 수정】

* JS가 생성하는 마크업과 변경하는 클래스·스타일을 CSS와 함께 분석할 것.
* JS가 인라인 스타일로 CSS를 덮어쓰는 경우 실제 적용 경로를 확인할 것.
* 색상 등 순수한 시각적 값이 JS에 고정되어 있다면 기능에 사용되는 값이 아닌지 확인한 뒤 수정할 수 있음.
* 요소 크기·위치·스크롤 계산에 사용되는 값은 디자인 값으로 간주해 임의로 바꾸지 말 것.
* CSS 클래스가 JS의 상태 판별이나 요소 탐색에 사용되는 경우 해당 의미를 유지할 것.
* JS가 생성하는 HTML의 태그 구조, 클래스, ID, 데이터 속성을 원칙적으로 유지할 것.
* 새로운 클래스나 DOM 구조가 반드시 필요하면 먼저 이유와 영향 범위를 설명할 것.
* iframe 내부와 부모 문서의 적용 범위를 구분하고 동일 출처 제한을 우회하려 하지 말 것.
