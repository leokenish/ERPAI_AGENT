# 카카오톡에서 추출한 업무맥락 — 자료 안내

- 프로젝트명: 카카오톡에서 추출한 업무맥락
- 대화 주제: 카카오톡 TXT와 첨부 이미지를 연결하여 AI 에이전트용 업무맥락 MD 보완
- 정리 기준일: 2026-10-08, Asia/Seoul
- 추출 묶음 버전: 1.0
- 문서 성격: 확인 가능한 대화의 추출본 + 교육 콘텐츠 초안. 현재 업무규정이나 운영 매뉴얼의 승인본이 아니다.

## 1. 목적과 현재 상태

업무 주관부서 담당자와 주고받은 카카오톡 대화를 AI 에이전트가 참고할 업무 지식으로 전환하는 프로젝트다. 사용자는 이미 대화를 TXT로 추출하고 업무 MD를 만들었다고 설명했으나, 첨부 이미지는 읽지 못했다고 보고했다. 이어 이미지에 표시되는 날짜·시간을 이용해 해당 대화와 연결하고 MD의 정확도를 높일 수 있는지 문의했다. [D1]

이 대화에서 제안된 보완 방식은 메시지 시각, TXT의 사진 표시, 이미지 파일명·시각, 이미지 속 내용, 앞뒤 대화를 함께 대조하는 것이다. 이미지에 보이는 현상과 담당자의 요청, 최종 합의·처리 결과를 분리하고, 연결 근거와 확신도를 남기도록 제안했다. 실제 TXT·이미지 묶음으로 이 방식을 시험한 결과는 확인되지 않는다. [D2]

이번 추출본은 여러 프로젝트의 자료를 통합할 ‘ERP AI 에이전트 교육 포털’에 제공할 입력 자료다. 포털 구현, 서버 설치, GitHub push, SAP 변경은 수행하지 않았다. [D3]

## 2. 상태를 읽는 방법

‘작업 단계’와 ‘근거 수준’을 따로 읽는다. 제안 문서의 존재는 해당 기능의 구현이나 검증을 뜻하지 않는다.

| 항목 | 작업 단계·현재 상태 | 근거 수준 |
|---|---|---|
| 카카오톡 대화 TXT 추출 | 완료했다고 사용자 보고 | TXT 실물과 추출 범위는 이 대화의 대상 파일로 확정하지 못함 [D1] |
| TXT 기반 업무 MD 작성 | 완료했다고 사용자 보고 | 기존 MD의 파일명·본문·최신 버전 미확인 [D1] |
| 첨부 이미지 반영 | 반영하지 못했다고 사용자 보고 | 이미지 읽기 실패 원인·도구·로그 미확인 [D1] |
| 날짜·내용을 함께 쓰는 이미지 연결 | 제안 | 설계 설명만 확인, 매칭 결과 없음 [D2] |
| 이미지 반영 MD 재작성 | 착수 여부 미확인 | 개선본을 확인하지 못함 |
| 담당자 검수·정확도 평가 | 수행 여부 미확인 | 검수 기록·정답 연결표 없음 |
| 이번 교육 자료 추출 | MD 4개와 ZIP 작성 | 문서 구조·링크·ZIP 일치 검증에 한정 |
| 포털·GitHub·Node.js 배포 | 사용자가 제시한 향후 활용 계획 | 이번 작업에서 구현하지 않음 [D3] |

### 3.2 파일 및 보조 자료 확인

- 관련 파일 검색에서 기존 업무지식 정제 TXT 4개를 발견하고, 각각 1~80행의 제목·범위·주의사항·일부 지식카드를 읽었다. 전체 본문이나 대응 원문 대조는 수행하지 않았다. 정확한 이름, 읽은 범위, 식별자는 [자료목록 A](03_자료목록과보완사항.md#a-기존-자료-목록)에 기록했다.
- 이 네 파일은 검색 결과의 루트 경로에 있었다. 이 대화방의 산출물인지, D1에서 말한 MD의 이전 자료인지, 현재 어떤 파일로 대체되었는지는 확인되지 않는다. 현재 프로젝트의 실적·정책으로 편입하지 않았다.
- 관련 검색에서 `/ERP Git 관리를 위한 추출 및 배포/` 경로의 파일도 나타났다. 다른 프로젝트의 후보로 분리했으며, 이번 프로젝트의 실행 이력으로 사용하지 않았다.
- `zhr5-knowledge-curation/SKILL.md`는 제공된 현행 스킬 본문을 모두 읽었다. 출처·시점·개인정보·미확인 상태를 구분하는 정리 원칙만 적용했다. 사용자 저장소의 설치 상태나 최신 버전을 확인한 것은 아니다. [S1]
- 과거 대화 확인 기능으로 관련 맥락을 보완 조회했으나, 이 프로젝트의 추가 원문 전체나 이미지 매칭 결과를 확보하지 못했다. 다른 프로젝트의 요약 결과는 구현 근거로 쓰지 않았다.

### 3.3 접근 범위의 한계

- 현재 표시된 메시지보다 앞선 이 프로젝트의 전체 대화를 모두 읽었다고 보장할 수 없다.
- `/카카오톡에서 추출한 업무맥락`이라는 파일 경로를 조회했지만 해당 경로는 검색되지 않았다. 이것은 프로젝트 자료가 없다는 증거가 아니다. 대화 프로젝트명과 파일 폴더명은 같지 않을 수 있다.
- 이번 확인은 관련 검색어·제목 기반 탐색이다. 전체 보관 파일에 대한 완전한 전수조사는 아니다.
- 사용자의 맥, GitHub 저장소, 기존 MD 폴더, ERP 서버에는 접속하지 않았다.
- 실제 첨부 이미지, 원본 TXT와 이미지의 대응표, 이미지 시각 표시 화면, AI 오류 로그는 확보하지 못했다.
- 이미지 OCR·육안 판독, TXT 메시지 파싱, 이미지 시간 검증, 매칭 정확도 평가는 실행하지 않았다.

## 6. 통합 담당자 인계 요약

이 묶음의 핵심은 ‘AI가 날짜만 보고 이미지를 자동 확정한다’가 아니다. **시간과 내용으로 연결 후보를 만들고, 사실·요청·합의·결과를 나눠 근거 있는 지식으로 검수한다**는 설계다. [D2]

우선 필요한 보완은 ① 대상 TXT·기존 MD의 실물과 버전, ② 대응 이미지 원본, ③ 날짜·시간이 무엇을 뜻하는지 확인할 화면, ④ 사람이 확인한 소규모 정답 연결표다. 이 네 가지 없이 ‘이미지 통합 완료’ 또는 ‘정확도 향상 검증 완료’로 상태를 올리면 안 된다.

출처 ID의 상세 설명은 [01 문서 제16절](01_프로젝트_맥락과설계.md#16-주요-내용의-출처)을 따른다.
