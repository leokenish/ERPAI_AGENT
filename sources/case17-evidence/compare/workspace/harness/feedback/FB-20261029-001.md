# 업무 피드백

- ID: FB-20261029-001
- 기록일: 2026-10-29
- 대상: 선택근무 8~9월 단가 경계, ZTHREDITCOST, ZRPTH411_COMPARE, 대휴실비/보유금액.
- 원래 질문: 2026-09-01에 8,400→9,240원으로 인상된 선택기간의 비교 금액차이 원인과 날짜별 계산 개선 가능성.
- 앞선 설명의 보완: 수기보정 존재만으로는 작성 목적을 확정할 수 없었다. 사용자가 날짜별 인상분 수기 계산을 등록한 것임을 명시했다. 대휴 발생일 저장·사원정보 조회 사실과 금액 계산용 단가 출처를 구별할 필요가 있다.
- 사용자 정정/제안: 기간 시작일 단가 일괄 계산을 보완하려고 인사부가 일자별 수기 계산 후 ZTHREDITCOST에 입력. 연장/야간/휴일/대휴를 인상 전후로 계산할 수 있는지 검토 요청. 대휴 발생일 단가 조회는 사용자의 추정으로 제시되어 소스로 검토.
- 근거: SRC-23 사용자 발화 전체, 2026-10-29; SRC-17 KSP/300 추출본과 현재 로컬 비교 리포트의 실제 소스. 구체적 위치는 아래 검토서에 기록.
- 원인 분류: 수기 운영 목적 추가 확인; 기간 합계와 일별 단가 귀속 구분; 대휴 사원정보 기준일과 금액 단가 출처 혼동 방지.
- 처리 상태: UPDATED / REVIEW_REQUIRED. 문서와 검토안 갱신, 담당자 검토 대기. 소스 구현·SAP 검증은 미수행.
- 수정 파일과 이유: [검토서](../../knowledge/processes/selective-rate-boundary-review.md)를 기준 원본으로 추가. 단가 정책·정산 재구성·코드 연결·색인·미확인 사항·선택/단가 지도·출처 등록부에 연결. 기존 사용자 변경과 과거 기록 보존.
- 핵심 판단: 4주 판정을 유지하고 일별 지급분에 날짜별 유효 단가 적용. 기간 대휴실비는 현재 시작일 단가, BS01 보유금액은 원천 실적 단가 상속. 익일 분리 저장에서 재조회되는 경로도 있으므로 모두 정상/오류라고 단정하지 않음. 현 합계의 TDCOST 별도 보존.
- 회귀 기준 원본: [tests/business-qa.md](../../tests/business-qa.md) Q70–Q74. AI 작성·담당자 검토 대기, 독립 평가 아님.
- 검증: 최종 실행 결과는 [docs/VALIDATION.md](../../docs/VALIDATION.md)의 같은 날짜 기록에 연결한다. 작업 시작 시 506개 ABAP의 SHA-256을 확보하여 종료 시 대조.
- 남은 확인: 지급시간 날짜 귀속, 여러 날짜 대휴 합산, 유효 등급/단가, 수기 원 단위 처리, 실제 행/활성 소스 및 SAP 재실행. 전원 차액 0원·실제 지급 정확성은 미확정.

- 같은 날 후속 정정: 자정 단가 분리 제안은 철회하고 입력 시작일 기준·기존 대휴 확보 단가 유지·시차/재량/간주 인상 제외로 보완했다. [FB-20261029-003](FB-20261029-003.md)을 현재 검토 기준으로 함께 읽는다.
