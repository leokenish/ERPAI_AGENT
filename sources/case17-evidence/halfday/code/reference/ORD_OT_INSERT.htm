알립니다

  • 2018.6.11.부터 근무종료 후 3일(단체협약상의 휴일 제외) 이내 결재상신을 마쳐야하며, 결재상신 후 2일(단체협약상의 휴일 제외) 이내 수정 및 결재 가능
    ※ 결재상신 후 수정 방법 : <회수> 후 <수정>하여 재상신
  • 해외출장, 1주 이상 국내출장, 휴가 기간 중 근무, 기타 불가피한 경우(개인 또는 결재권자 부주의 제외)는 5일(단체협약상의 휴일 제외) 이내 부장급 부서장의 코비스 내부결재를 받아 신청가능 (공람지정 또는 팩스송부 / FAX : 1449, 문의 : 1412 ) <신청 양식 다운받기>
  • 해외출장 결재 완료 시, 자동으로 시간외 신청 시 총 근무시간 9시간(휴게시간 제외) 초과분부터 연장실비 발생
  • 통상(시차) 익휴 관련안내 : 우측 도움말 참조 <통상(시차) 익휴 도움말 조회하기>
  • 시간외 신청 순서 : 입력사항 입력 → <저장>버튼 클릭 → <결재상신>버튼 클릭
  • 결재상신전 변경 순서 : '시간외 근무내역'에서 미상신건 선택 → <수정>버튼 클릭 → 내용변경 후, <저장>버튼 클릭
  • 회수 후 재상신 순서 : '시간외 근무내역'에서 결재중건 선택 → <회수>버튼 클릭 → '시간외 근무내역'에서 회수건 선택 → <수정>버튼 클릭 → 내용변경 후, <저장>버튼 클릭 → <결재상신>버튼 클릭
  • 삭제 : 결재상신전이나 결재완료후 신청건 삭제할 수 있음 ( 단, 지급완료건은 삭제불가! )
