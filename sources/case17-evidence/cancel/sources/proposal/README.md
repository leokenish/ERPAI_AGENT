# 선택근로 기간·실적 삭제 프로그램

2026-10-29 사용자 수정 요구를 반영한 신규 개발안. 담당자 검토 대기, SAP 미반영·구문/실행 미검증. 추출 원본 변경 없음.

## 현재 파일과 입력

[ZHR_CW_MEMBER_DEL.abap](ZHR_CW_MEMBER_DEL.abap). 필수 입력은 사번, 선택근무 시작일, 종료일이다. 자료형은 ZTHR0132를 참조한다. 선택화면 텍스트를 p_pernr=사번, p_begda=선택근무 시작일, p_endda=선택근무 종료일로 등록한다.

## 2026-10-29 변경

PA9021 조회/원본 비교/삭제/건수 출력/타입 참조를 모두 제거했다. PA0001 조회와 정보형 9021 전용 P_ORGIN 검사도 제거하고 전용 인사부 트랜잭션 권한 검사는 유지했다. 변경 전 사본·패치·전후 해시는 [revisions/20261029-two-tables](revisions/20261029-two-tables)에 보관한다. 사용자 붙여넣기 코드와 저장소의 해당 FORM은 같은 내용이었으며 저장소 전체 프로그램의 관련 선언·검사·출력까지 일관되게 수정했다.

## 삭제와 보호 조건

- ZTHR0132: 사번·시작일·종료일 정확 일치, 선택근로 0110인 기간이 정확히 1건이어야 한다.
- ZTHR0112: 같은 사번·기간·근로유형·근무주기의 실적 전체를 물리 삭제한다. 결재 연결과 상태로 차단하지 않는다. 익일/복수 행도 기간 키로 포함한다.
- 종료일 YYYYMM으로 ZTHR0160의 선택근로 마감을 검사한다. 마감 행, 해당 기간 ZTHR0113 정산 이력, 실적 ZADMIT_DT가 있으면 차단한다.
- 확인창 후 직원/테이블 잠금을 얻고 두 테이블 전체 값을 다시 비교한다. 중간 COMMIT 없이 두 DELETE를 수행하고 성공 시 한 번 저장한다. SQL 오류·건수 불일치는 전체 ROLLBACK한다.
- PA9021과 대휴 ZTHRBS01은 조회/수정/삭제하지 않는다. 결재/정산/지급 테이블도 변경하지 않는다.

## 권한·적용 조건

전용 트랜잭션 ZHR_CW_DEL을 이 리포트에 연결하여 인사부에만 부여한다. SE38 실행에서도 S_TCODE를 검사한다. 현재는 해당 전용 권한 기준이며 직원별 정보형/조직 권한 검사는 하지 않는다.

PA9021이 유지되므로 기존 기간 생성 프로그램 실행 시 삭제한 ZTHR0132가 다시 생성될 가능성이 있다. 이번 요구에 따라 마스터는 건드리지 않는다.

ENQUEUE_E_TABLE은 기존 마감/입력/기간생성 코드가 자동 준수하는 잠금이 아니다. 운영 전 공유 잠금 연계 또는 동시 쓰기 금지 통제가 필요하다. 재검사만으로 검사 직후 경쟁 상태까지 차단한다고 주장하지 않는다. 결재함에서 삭제 실적 상세/승인 시 오류나 재생성 여부도 확인한다.

화면 결과는 영구 감사원장이 아니다. 영구 백업/감사 체계는 별도로 연결한다.
