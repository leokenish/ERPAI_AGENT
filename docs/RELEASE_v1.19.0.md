# v1.19.0 변경 및 검증

기준: v1.18.2 Full ZIP. 작성일: 2026-10-28.

## 변경

- 05 과정의 ‘대화와 첨부의 맥락 보존’을 ‘업무 메신저 대화 맥락 보존’으로 변경했습니다.
- 전체 TXT 검토, 업무별 분리, ID 부여, 날짜 구분, 질문·설명·합의·후속 정정의 의미, 지식 문서 연결을 상세히 설명했습니다.
- 실제 SRC-11의 교대근무 입력 기본값과 신입 계약직 등급 변경 대화를 발췌했습니다. 세 실제 발화자를 우대리·나팀장·이과장으로 고정 치환하고 이름·사번을 가렸습니다. 자연스러운 말투와 시간은 유지합니다.
- 두 사례의 메신저 대화 / 정리된 업무카드 / 함께 보기 전환 및 발췌·업무카드 MD 다운로드를 제공합니다. KC ID는 이번 교육용으로 부여했습니다.
- 명시적인 사례 문답 6쌍과 프로젝트 대화에 큰 원형 표정 프로필을 추가했습니다. 네 가상 인물을 에피소드별로 분산 배정하고 에피소드 안에서는 유지합니다. AI 응답에는 비인간형 로봇 프로필을 사용합니다.
- 표정은 발화 맥락을 설명하기 위한 연출이며 실제 인물의 감정을 단정하지 않습니다. 기존 인물 프로필 원본을 수정하지 않고 CSS로 얼굴 영역을 표시합니다.

## 적용

GitHub 커밋·push·운영 배포는 수행하지 않았습니다. 로컬 병합 후 build, preview:file, test를 수행하고 변경 범위를 검토한 다음 사용자의 저장소에 반영합니다.
