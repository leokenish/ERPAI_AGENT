# v1.17.1 · 모든 과정의 근거 자료 확인

수정일: 2026-10-27. 기준: v1.17.0 Full ZIP.

## 변경 내용

- 01–16과정의 근거 영역 제목을 ‘근거 자료 확인’으로 통일했다.
- 근거 영역의 부연 설명·대화 식별자·다음 읽기 안내를 제거하고 해당 프로젝트 자료실 링크만 남겼다.
- 05–07은 이미 요청에 맞춰 정리한 개별 MD 링크·본문·HTML 관계도를 그대로 유지했다.
- 13 포털 구축은 핵심 MD의 ‘프로젝트 진행’ 자료실에 있는 포털 intent.md·spec.md·plan.md·insight.md로 각각 연결한다.
- 근거 영역 밖의 본문·도입 설명·기존 대화·다운로드·이미지·화면 코드는 보존했다. 파일 삭제는 없다.

## 검증

Node.js 24에서 빌드와 오프라인 미리보기 생성을 완료했고 기존 테스트 94개를 모두 통과했다. 16개 과정의 근거 영역이 제목과 자료실 링크만으로 구성되는지 확인했다. 링크 52개의 자료실 대상과 MD 경로·다운로드 파일을 대조했고 모두 유효했다. 근거 영역 밖의 본문과 05–07의 기존 파일, 보호 대상 1,732개 파일의 바이트 보존을 확인했다. 화면 코드와 배치 변경이 없는 문구·링크 수정으로, 이번에는 브라우저 검사를 반복하지 않았다. 검증 결과는 `docs/validation/v1.17.1/`에 기록한다.

## 로컬 반영

변경분 ZIP은 v1.17.0 기준이다. `project/` 안의 파일을 로컬 저장소의 같은 경로에 비교·병합한다. 로컬 수정이 있으면 보존하며, ZIP의 `CHANGE_MANIFEST.json`에서 파일별 전후 해시를 확인한다. 전체 ZIP은 이전 버전과 비교하거나 전체 소스가 필요할 때 사용한다.

`dist/`, `preview.html`, `preview-data/`는 생성물이므로 ZIP에서 제외했다. Node.js 24 이상에서 `npm run build`, `npm run preview:file`, `npm test`로 다시 생성·검증한다. GitHub 커밋·push·배포는 수행하지 않았다. ZIP 안 `APPLY.md`에 Codex Desktop용 적용 프롬프트를 포함한다.
