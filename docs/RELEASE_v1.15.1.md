작성일: 2026-10-26 (Asia/Seoul)

## 결과

최근 추가된 소스 추출·진단, WEBGUI, 업무일지 타임라인, 스마트 ERP 대화를 기존 사용자·AI 문체에 맞췄습니다. 사용자 요청은 자연스러운 ‘주세요/마세요’ 체와 해요체로, AI 설명은 ‘입니다/하겠습니다’ 체로 정리했습니다. 맞춤법·띄어쓰기와 문장 끝의 기계적인 치환 오류도 수정했습니다.

최근 추가 179쌍과 직전 WEBGUI 추가 20쌍, 총 199쌍·398개 위치를 검토했습니다. 이 중 본문이 있는 394개를 읽고 사용자 167개·AI 60개, 총 227개 표시 문장을 교정했습니다. 이미 자연스러운 경어체인 항목, 파일·오류 문자열만 있는 항목, 본문이 없는 4개 위치는 유지했습니다.

| 프로젝트 | 검토 위치 | 사용자 교정 | AI 교정 |
|---|---:|---:|---:|
| 소스 추출 및 진단, 업무 에이전트 | 68 | 29 | 10 |
| ERP WEBGUI 개편 | 172 | 59 | 21 |
| 업무일지 타임라인 개발 | 60 | 30 | 14 |
| 스마트 ERP 메인화면 개편 | 98 | 49 | 15 |
| 합계 | 398 | 167 | 60 |

예를 들어 ‘보여 주세요봐’는 ‘보여 주세요’로, ‘만들어 주세요야해’는 문맥에 맞는 ‘만들어 주세요’로, ‘볼수잇어?’는 ‘확인할 수 있나요?’로 다듬었습니다. ‘재무회게’, ‘육각향’, ‘진담’ 같은 일반 문장의 오탈자도 바로잡았습니다.

긴 문서 작성 요청이나 AI가 제공한 복사용 프롬프트도 생략하지 않았습니다. AI 답변 속 복사용 요청문은 요청문의 역할을 유지해 주세요/마세요 체로 편집했고, 이를 AI의 작업 완료 보고로 바꾸지 않았습니다.

## 변경과 보존

- 실제 표시 내용은 `content/conversations/editorial-prompts.json`, `editorial-responses.json`에 반영했습니다. 원문 SHA-256, 역할, 확보 수준과 연결합니다.
- `sources/`의 1,576개 파일과 표시 편집 파일을 제외한 대화 콘텐츠 66개 파일은 기준 ZIP과 바이트 단위로 같습니다. 대화 원문·순서·이미지·코드·파일명·첨부·URL을 변경하지 않았습니다.
- 원문 JSON·전문 MD 다운로드는 원문을 유지하며, 화면의 표시 문장·복사·검색에는 교정본을 사용합니다.
- 기술적인 식별자나 오류 인용의 철자는 임의로 고치지 않았습니다. 예를 들어 다음 답변에서 정정되는 `ZMZP014_1`, 오류 문자열의 `exsit`, 파일명 `copy_respone.txt`는 당시 맥락을 보존합니다.
- 타임라인의 ‘2번쨰 사진’은 ‘두 번째 캡처’로 고쳤습니다. 수치의 의미를 바꾼 것이 아닙니다. 그 외 숫자 토큰도 교정 전후 대조했습니다.
- 포털 전체는 9개 대화 프로젝트·147개 에피소드·1,327개 위치, 본문 1,309개와 미확보 18개로 동일합니다. 미확보 응답을 새로 작성하지 않았습니다.
- 버전, README, 통합 기록, 검증 기록을 갱신했습니다. AI 편집 건수를 확인하는 기존 검사의 기대값을 375개로 갱신했습니다. 새로 추가한 AI 편집은 59개이며 기존 편집 1개도 다시 교정했습니다.

교정 ID와 전후 표시 해시: `docs/EDITORIAL_REVIEW_v1.15.1.json`.

## 로컬 적용

v1.15.0을 적용한 저장소에는 `KBS_ERP_AI_Agent_v1.15.1_Changes.zip`의 `project/` 변경분만 비교·반영합니다. 이번 v1.15.0 → v1.15.1 변경에는 삭제 파일이 없습니다. 상세 경로·전후 해시는 ZIP의 `CHANGE_MANIFEST.json`에 있습니다.

Node.js 24 이상에서 `npm run build`, `npm run preview:file`, `npm test`, `npm start` 순으로 확인합니다. 생성된 `dist/`, `preview.html`, `preview-data/`는 Git 추적에서 제외합니다. 기존 `.git`·로컬 설정·별도 변경은 보존하며 사용자가 검토 후 커밋·push합니다.
