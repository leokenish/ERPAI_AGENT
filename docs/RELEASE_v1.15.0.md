## 저장소 정리와 배포 방식

v1.14.0 프로젝트 파일 합계 약 629MiB에서 약 238MiB로 **약 62%** 줄었습니다. 압축 크기나 과거 Git 이력 크기가 아닌, 패키지에 담는 프로젝트 파일의 비압축 합계 기준입니다.

- dist/, preview.html, preview-data/: 원본에서 재생성 가능하므로 Git 추적·전달 패키지에서 제외.
- 발표 기능의 JS/CSS/전용 테스트: 기능 삭제에 따라 제거.
- 원천 sources 1564개 파일: 기존 바이트 전부 동일.
- 기존 게시 대화 파일 67개: 카탈로그 명칭 외 본문·편집 기록 동일.
- 기존 AGENTS, 원천, 폰트, 히어로와 개발·보존 근거는 유지.
- GitHub Actions: Node 24로 빌드하고 dist만 Pages에 업로드. 설정 파일의 수정이며 실제 Actions 실행 검증은 push 후 필요.

과거 Git 이력의 대형 파일을 지우는 history rewrite나 강제 push는 하지 않았습니다.
