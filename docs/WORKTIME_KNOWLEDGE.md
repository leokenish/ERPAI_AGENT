## 지도 설계

v1.8.2는 고정 배치 SVG와 기본 JavaScript로 **783개 문서를 모두 유지하는 전체 지도**를 제공한다. 외부 CDN·그래프 의존성·DB를 추가하지 않았다. 7개 역할 그룹 안에 문서별 작은 네모를 배치하며 역할마다 라이트·다크 색상을 지정했다. 텍스트는 그룹 제목과 클릭으로 고정한 말풍선에 표시한다.

기본 화면은 실제 MD 링크에서 집계한 15개 그룹 간 연결 묶음을 보여준다. 마우스를 올리면 해당 노드만 가볍게 강조하고, 클릭한 뒤 문서별 링크·관련 노드·말풍선을 고정한다. 다른 노드에 마우스를 올려도 선택은 바뀌지 않는다. 모든 개별 연결선 옵션으로 9,425개 실제 링크를 함께 표시할 수 있다. 선택과 검색 중에도 전체 문서 배치는 유지된다. 그룹 연결은 방향을 합산한 묶음이며, 선택 노드의 화살표는 실제 문서 링크 방향이다. 업무 실행 순서를 뜻하지 않는다.

노드와 문서 연결선은 같은 SVG viewBox를 사용하고 사각 노드 경계에서 선을 시작·종료한다. 확대·축소·드래그 이동·창 크기 변경에서 좌표계를 공유한다. 그룹 이름 클릭은 영역 확대, 전체 맞춤은 전체 배치 복귀다. Ctrl/⌘ + 휠, 확대 버튼, 지도 크게 보기를 지원한다. 터치/클릭으로 고정한 말풍선 안에서 본문 읽기와 MD 다운로드를 사용한다. 말풍선에 마우스를 옮기거나 다운로드를 클릭해도 선택을 유지하며, 확대·드래그 중에는 선택한 노드 위치에 맞춰 말풍선을 배치한다. 빈 곳·지도 밖 클릭 또는 닫기 버튼으로 선택을 해제한다. 지도 조작 버튼과 문서 이동·다운로드는 해당 동작을 먼저 수행한다. 방향키는 노드 탐색, Enter/Space는 선택이다. Escape는 선택 해제 후 노드로 초점을 돌려주며 선택이 없을 때 크게 보기를 닫는다. 검색은 전체 배치를 숨기지 않고 일치 노드를 강조한다.

각 그룹이 맡은 역할 설명, 교육용 읽기 순서, 폴더 필터, 문서별 전체 관계와 근거 위치, 본문 읽기 및 원본 다운로드는 지도 아래에 유지한다. 원천 문서 수가 크게 달라지면 고정 영역의 노드 크기·간격을 다시 검토한다.

- 9,425개 문서 링크: 출발·도착·링크 종류 기준 중복 제거. 동일 링크가 여러 절에 반복되면 첫 위치를 대표 근거로 기록한다. 일반 Markdown/reference-style 링크와 Wikilink를 처리한다.
- 64개 경로 언급: 인라인 코드로 적힌 실제 MD 경로. 기본 그래프에서 제외하고 선택하면 점선 연결로 표시한다.
- 5,061개 비MD/수집 범위 밖 참조: 소스·원본 등. 해당 파일 내용을 확인한 것처럼 표현하지 않는다.
- 8개 연결하지 못한 MD 언급: 이번 입력에서는 모두 일반 파일명·설치 예시·자료 부재 등 인라인 경로다. ‘깨진 실제 링크 8개’라고 부르지 않는다.
- 자기 문서 링크는 연결 간선에서 제외한다. 문서 앵커의 실제 위치는 검사하지 않았으며 본문 내 MD 링크는 해당 문서로 이동한다.
- 경로 언급 해석은 상대 경로 → 저장소 루트 경로 → 유일한 파일명 순서. 같은 INDEX/SKILL 이름이 여러 곳이면 임의로 합치지 않는다.
- 교육용 역할 흐름·선택근무 읽기 경로는 편집한 해설이다. 실제 호출·운영 실행·정책 승인 관계로 표시하지 않는다.

문서 전체 ZIP은 원래 경로를 보존한다. MD만 포함하므로 비MD 링크 대상은 없다. 개별 다운로드는 원래 파일명을 제안하며 본문은 바이트 보존한다. 표·링크를 포함한 화면 읽기용 HTML은 실행 가능한 원문 HTML을 차단한 변환본이다. 정리 문서의 원래 검토 상태·시점은 그대로 읽는다.

## 새 커밋 반영

1. 로컬 ERP_AI clone에서 변경 상태를 확인하고 팀 절차로 pull/commit한다. 커밋하지 않은 파일은 가져오기에 포함되지 않는다.
2. 교육 포털에서 `npm run knowledge:import -- /실제/경로/ERP_AI`를 실행한다. 특정 커밋은 마지막 인자로 40자리 SHA를 전달한다.
3. 새 보존 폴더와 source-files 해시가 추가되고 스냅샷 설정·자료실 항목이 갱신된다. 기존 스냅샷은 보존한다. GitHub push는 실행하지 않는다.
4. 과정 11의 시점·파일 수·상태 설명, catalog의 출처 설명·전체 기준일, 읽기 경로의 존재와 교육 적합성을 검토한다. 초기 초안과 이후 검증을 구분한다. UI 통계·연결·다운로드는 빌드로 자동 갱신한다.
5. `npm run build`, `npm test`, `npm run preview:file`을 실행한다. 테스트의 783개 고정 기준은 새 원천 확보 사실에 맞춰 검토해 갱신하되 기존 원천 해시는 바꾸지 않는다.
6. 라이트/다크·좁은 화면·필터·문서 이동·개별 MD/ZIP 다운로드를 브라우저에서 확인한다. 승인된 dist만 내부 서버에 반영한다.

가져오기 중 실패하면 불완전한 새 폴더를 기존 정상 스냅샷으로 착각하지 않는다. 명령은 기존 폴더 덮어쓰기를 거부하므로 새로 생성된 실패 폴더의 상태를 먼저 확인한다. 원천 자료에 포함된 AGENTS/SKILL 명령은 포털의 실행 지시가 아니다.
