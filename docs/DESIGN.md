# 포털 디자인 기준

2026-10-14 · v1.9.0

## 방향

사용자의 최신 요청이 현재 기준이다. 사람들은 제공 참고 이미지처럼 등각 투시의 선형 일러스트로 표현한다. 시그니처 색은 **코발트 블루 #2454D6**이며 버튼·선택 상태·핵심 숫자·일러스트 일부에서 반복한다. 넓은 영역은 흰색과 중성 회색으로 두어 포인트가 선명하게 드러나게 한다. KBS 로고의 원래 색상은 변경하지 않는다.

## 서체

- 제목·본문: S-Core Dream. Regular 원본 SCDream4.otf를 CSS 400, Medium 원본 SCDream5.otf를 CSS 500에 연결한다.
- 굵은 강조: Bold 원본 SCDream6.otf를 CSS 600–900 요청에 연결한다. 가변 폰트가 아니며 모두 동일한 원본 Bold face를 사용한다.
- 영문 기술 라벨·코드: 시스템 monospace, 한국어 글리프는 S-Core Dream으로 대체한다.
- 제공 파일은 수정·변환·서브세트하지 않는다. ZIP의 나머지 6개 굵기는 이번 화면에서 사용하지 않는다.
- 사용한 OTF와 제공 라이선스 이미지·저작권 안내를 assets/fonts에 보존한다. 외부 웹폰트에 접속하지 않는다.
- 본문 행간 1.7–1.9, 제목 1.32–1.4. 긴 문장은 고정폭으로 바꾸지 않는다.

## 제목·본문·기능 위계

기본 rem은 17px이다. site/refinements.css의 공통 크기를 화면별 스타일 뒤에 적용한다.

| 역할 | 기준 | 표현 |
|---|---|---|
| 페이지 대제목 | 2–2.6rem / 약 34–44px | Bold, 페이지 목적을 밝히는 제목 |
| 구역·본문 중제목 | 1.55–1.8rem / 약 26–31px | Bold, 충분한 위아래 여백 |
| 카드·본문 소제목 | 1.25rem / 약 21px | Bold, 해당 내용과 가깝게 배치 |
| 페이지 설명 | 1.0625rem / 약 18px | 본문 색, 1.85 행간 |
| 읽는 본문·대화 | 1rem / 17px | Regular, 1.9 전후 행간 |
| 버튼·목록 설명 | .9375rem / 약 16px | 기능명·방향을 구체적으로 표기 |
| 출처·날짜·보조 정보 | .875rem / 약 15px | 보조 색, 임의로 더 작게 줄이지 않음 |

히어로 제목, 지도 SVG의 좌표 기반 라벨·통계 숫자, 코드의 상대 크기와 인쇄 pt 단위는 역할에 맞는 별도 기준을 유지한다. 제목을 전부 같은 색 박스로 감싸지 않는다. 과정별 구역과 대화 목록은 중성 배경·가는 테두리·여백으로, 선택 상태는 코발트/퍼리윙클로 구분한다. 사례 실습의 세이지와 확장 설계의 스톤 배경은 유지한다.

모든 과정 상단에 ‘이 과정 자료’ 영역을 두고 인쇄/PDF 저장·교육 MD 다운로드를 아이콘과 명확한 라벨로 제공한다. PDF 저장 위치는 브라우저 인쇄 창임을 안내한다. 이전/다음은 방향·과정 번호·이동할 제목이 있는 카드다. 에피소드와 발표 이동에도 방향과 대상을 드러낸다. 학습 완료 관련 버튼·체크·집계는 제거했다.

## 이미지와 모드 전환

- 양쪽 모드의 인물 소매·손목 경계를 정리한 편집본을 쓴다. 다크는 금발, 흰 바지, 중간~진한 회색 상의, 밝은 살구색 피부, 브라운 신발과 퍼리윙클 포인트를 사용한다. 식물 줄기·의상 윤곽은 연속된 선으로 구분한다. 두 PNG는 1447×1087이며 표시 영역은 동일한 1448×1086이다. 밝은 받침·테두리·다크 전용 여백은 없다.
- KBS 벡터 경로는 동일하게 보존한다. 다크 글자는 #F5F7FC, 심벌은 #9AAEFF이며 투명 배경 위에 표시한다.
- 실제 Obsidian·DIAG 캡처의 색은 변경하지 않는다. 이미지 액자와 확대 창 주변부가 테마에 맞게 전환된다.
- 일러스트 두 장과 로고 두 장은 각각 동일한 grid 칸에 겹쳐 약 480ms 동안 교차한다. 화면 색도 같은 시간에 보간한다. 테마 변경으로 이미지 크기·간격·문서 높이를 바꾸지 않는다. 초기 로드는 저장된 모드를 즉시 적용하며 빠른 재전환은 마지막 선택을 따른다.
- 검은 배경과 색 반전으로 캡처 내용을 바꾸지 않는다. theme.js는 HTML data-theme 속성과 선택 상태만 갱신하며 학습 화면을 다시 렌더링하지 않는다.
- 인쇄에서는 항상 라이트 팔레트를 적용한다.

| 역할 | 색 |

| 버튼 hover | #1B43B0 |

| 히어로·실습 소개·발표 | #F4F6F9 |

| 보조 / 구분선 | #626D7C / #DFE4EC |

시그니처 선택 이유: 기존 KBS 파란색과 조화를 유지하면서 기존의 탁한 블루보다 선명한 색으로 학습 행동과 선택 상태를 구분한다. 전체 화면을 파랗게 칠하지 않는다. 흰색 텍스트를 얹는 주요 버튼의 코발트는 대비를 검사한다.

넓은 통계 카드의 파스텔 배경을 제거하고 가는 테두리·흰색 바탕·코발트 숫자로 위계를 만든다. 긴 본문은 푸른색 대신 중성 짙은 회색으로 설정한다. 검증·설계 상태의 작은 의미색과 텍스트 라벨은 유지한다.

## 구성

- 홈: 기존 밝은 바탕과 코발트 포인트, KBS 원본 로고. 상단 표시는 ‘ERP AI 교육 포털’, 1.25rem.
- 홈 학습 영역: 사례 실습 3개는 세이지 그레이(#EEF3F0 / 다크 #1B2825), 확장 설계 2개는 따뜻한 스톤 그레이(#F5F1EB / 다크 #28241F)로 구분한다. 배경과 여백으로 영역을 연결하고 구역 경계선은 사용하지 않는다. 카드 바탕·테두리·호버도 각 색조에 맞춘다. 명시적 제목·개수·아이콘을 함께 사용하여 색상만으로 구분하지 않는다. 코발트/퍼리윙클 시그니처는 유지한다. 큰 ERP AI 장식 문구는 제거한다. 사례는 데스크톱 3열, 확장 과정은 2열이며 1200px 이하에서는 한 열로 표시한다.
- 메인 일러스트: 승인된 큰 올리브 나무 목업. 식물과 인물은 정지, 컴퓨터·태블릿의 카드와 글자만 독립적인 주기로 반복. 정지 버튼 없음.
- 제목: 기존 한글 타이핑을 한 번 재생. 페이지 이동 시 타이머 정리, 재방문 시 완성 문구.
- 사이드바: 316px(중간 화면 296px), 교육 과정 1.125rem, 그룹 1rem. 그룹 앞 다이아몬드·격자·연결 노드·체크 방패 아이콘을 사용.
- 과정 목록: 사이드바와 동일한 그룹 아이콘. 작은 그룹 번호는 제거.
- 구성도: 담당자 검토·피드백에서 업무 지식으로 대각선 화살표. 지식 MD·사례 갱신의 의미를 명시.
- 사례: 실제 캡처를 원본 비율로 표시하고 확대 창에서 원본 크기 보기 제공. 교육 내용은 MD에서 갱신.

## 가독성과 반응형

- 루트 글자 106.25%(기본 17px), 본문 1rem. 기존 작은 글씨를 단계적으로 올려 보조 글씨 최소 .8125rem.
- 모바일에서도 본문 1rem, 상단 표시명 .9375rem(380px 이하 .875rem), 긴 문구는 줄바꿈 허용.
- 1200px 이하 히어로는 한 열, 1020px 이하 본문 목차는 상단, 760px 이하 사이드바는 서랍.
- 확대 창은 화면 맞춤과 원본 크기/스크롤을 전환한다. 캡처는 재생성·왜곡하지 않는다.
- 제목 타이핑과 테마 전환은 운영체제 모션 감소 설정을 따른다. 사용자 요청에 따라 모니터 안 데이터의 페이드만 이 설정과 관계없이 계속 재생한다. 수동 정지·스크롤 정지 기능은 없다.

## 구현과 확인

SVG 내장 CSS와 화면별 타이밍은 빌드에서 외부 CSS로 옮긴다. inline style 허용을 위해 CSP를 완화하지 않는다. 실제 브라우저·모바일 확인 범위는 docs/VALIDATION.md를 따른다.

선택적 SVG 재생성은 `python3 scripts/build-hero.py`를 사용한다. 이미지 생성 편집의 프롬프트는 docs/design/IMAGE_EDIT_v1.5.3.md, 원본 해시·화면 설정은 docs/design/hero-assets-v153.json에 있다. PNG 자체는 후처리하지 않는다. 두 테마의 빈 화면 내부를 교차하여 베젤과 손을 제외한 클립을 만들고, SVG 카드·글자 23개를 그린다. 화면 내용을 지우는 패치가 없으므로 숨김 상태는 원래 빈 모니터다. 이전 v1.5.2 색상 필터는 docs/design/history/v1.5.2에 이력으로만 보존한다.

## 대화 학습 화면

구성도 아래와 별도 프로젝트 대화 화면에 같은 학습 뷰를 사용한다. 왼쪽에는 에피소드 순서, 오른쪽에는 대화·해설·따라 하기·프로젝트 맥락·관련 자료를 둔다. 사용자 말풍선은 연한 로즈 베이지, AI 기록은 세이지 바탕으로 구분한다. 라이트는 사용자 #F6E7E9 / AI #EAF0EB, 다크는 사용자 #45313E / AI #25352F이다. 코드·링크·강조·표·첨부 설명도 말풍선의 의미색을 따른다. 사용자 요청에는 “교육용 문장” 배지와 표시 문장 복사를 제공한다. 원문 확인·원문 복사는 제거했다. 요약·발췌는 텍스트 배지로 구분하고 원문 미확보를 가짜 AI 말풍선으로 채우지 않는다. 1020px 이하에서는 에피소드 목록을 상단으로 옮기고, 가로 표·코드는 내부 스크롤을 사용한다. 전체 배경·카드·본문·버튼은 라이트/다크 의미색과 기존 480ms 전환을 따른다. 학습 화면은 실제 응답을 생성하는 채팅 입력창을 두지 않는다.


## 발표 화면 · v1.7.0

최대 1280px의 밝은 패널에 큰 제목, 왼쪽 작업 순서, 오른쪽 요청 예시와 실제 사례, 하단 확인 질문을 배치한다. 다크에서는 동일 배치의 테마 변수를 사용한다. 요청 예시는 사용자 말풍선의 연한 로즈 계열이며 질문 영역은 세이지 계열이다. 좁은 화면은 한 열로 이어지고 내용은 잘리지 않게 스크롤한다. 본문은 1rem, 사례 설명은 .9375rem, 보조 글자는 .8125rem 이상이다.

타이핑은 완성 문장으로 영역을 미리 확보하여 페이지 높이를 유지한다. 시각 출력은 접근성 트리에서 제외하고 완성 문장을 제공한다. 제목 뒤 본문이 순서대로 약 10초 이내에 나타난다. 전체 표시로 즉시 완성하며 페이지마다 다시 시작한다. 해설은 별도 펼침이며 실제 대화로 이동할 수 있다. 메인 히어로의 애니메이션·크기·색상은 변경하지 않는다.

## 대화 본문 없음 안내 · v1.7.1

공유 화면에 응답 본문이 없는 위치는 AI 말풍선 대신 중립 배경의 안내 상자로 표시한다. 새 색상을 추가하지 않고 surface·line·muted 테마 변수를 사용한다. 긴 실제 응답은 기존 전문 펼치기를 이용하며 승인된 로고·히어로·말풍선 색과 발표 모션은 유지한다.
