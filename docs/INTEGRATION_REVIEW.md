# v1.12.0 에이전트 프로젝트 공유 사이트 전환 · 2026-10-24

사용자가 요청한 7개 화면 변경을 반영했습니다. 표시는 ‘ERP AI 에이전트’로 통일하고 홈 문구·영문 레이블·구성도 탭·에이전트 활용 사례 메뉴와 로봇 아이콘을 변경했습니다. 사례실습의 메뉴·홈 카드·상호작용 화면을 제거했으며 과거 주소는 관련 워크플로로 연결합니다.

자료실은 8개 소스 카드와 비어 있는 ‘핵심 MD 자료’로 구성합니다. 자료확인 창은 각 소스의 실제 MD만 나열하며 검색, 개별 다운로드, 전체 ZIP 다운로드를 제공합니다. 총 839개이며 개별 MD와 ZIP 구성 파일을 원천 바이트와 대조합니다. 기존 근로시간 지도 및 프로젝트 과정의 자료 접근은 유지합니다. 원천·대화·미확보 AI 응답·과거 검증 상태를 재작성하지 않았습니다.

이 변경은 최신 사용자 요청에 따른 것으로, AGENTS.md의 이전 사이트 이름·교육 목적·사례실습 노출보다 우선합니다. AGENTS.md와 .github 및 원천 파일은 그대로 보존합니다. 이 환경은 ZIP에서 분리한 작업 사본이며 .git이 없습니다. 사용자 PC의 로컬 수정은 확인하지 못했습니다. 원격 main은 기준 커밋 c9c22ea4a8aeb3d2ebc128948794099359c001a1로 확인했습니다. 10월 18일 index.lock 기록을 현재 실패 상태로 취급하지 않습니다.

이번 검증의 상세 결과와 다운로드 자동화 한계는 RELEASE_v1.12.0.md 및 패키지의 CHANGE_REPORT_v1.12.0.md에 구분해 기록합니다. 구현과 검증을 완료해 제공하며, 사용자 결과 승인·커밋·push·운영 반영은 아직 수행하지 않았습니다.
