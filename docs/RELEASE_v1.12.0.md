# v1.12.0 변경·검증·로컬 적용 안내

2026-10-24 작성. 이번 산출물은 사용자 요청 7개 항목을 반영한 수정 패키지입니다. 사용자 최종 승인과 운영 반영은 별도입니다.

## 변경한 화면

1. 사이트와 페이지 제목을 ‘ERP AI 에이전트’로 변경했습니다. 요청한 홈 문장과 SOURCES / EPISODES / WORK. FLOW / WORK FLOW를 반영했습니다.
2. 사례실습 메뉴·홈 카드·비교기·타이머 화면을 제거했습니다. 과거 사례 주소는 관련 워크플로로 연결합니다. 원천과 기존 비교 예제 파일 자체는 보존합니다.
3. 자료실에서 소스 카드가 바로 표시됩니다. MD 수만 표시하고 ‘교육 추출본 · 날짜’ 표시는 ‘추출본’으로 바꿨습니다. 별도의 프로그램 버전·확보 상태는 유지합니다.
4. ‘자료확인’은 해당 소스의 MD 목록 창을 엽니다. 이름·경로 검색, 개별 MD, 전체 ZIP을 제공합니다. 소스별 수는 20 / 4 / 4 / 6 / 6 / 11 / 783 / 5개입니다.
5. ‘핵심 MD 자료’는 공백입니다. 자료실의 기존 실습 자료·783개 지도 다운로드 버튼·실제 화면 보완 영역을 제거했습니다. 근로시간 워크플로 안의 지도·자료 다운로드는 유지합니다.
6. 구성도 탭은 ‘에이전트 구축’, ‘에이전트 협업,조회확장’입니다.
7. ‘에이전트 활용 사례’ 메뉴 그룹에 로봇 얼굴 아이콘을 사용합니다.

## 보존 범위

- 원천 자료·과거 대화·표시용 경어체 편집 데이터의 바이트와 줄바꿈을 보존했습니다. 원문에 없는 AI 답변을 만들지 않았습니다.
- KBS 로고, S-Core Dream, 색상, 올리브 나무·화면 모션, 제목 타이핑과 라이트·다크 모드를 유지합니다.
- 13개 워크플로, 7개 대화 프로젝트, 97개 에피소드와 미확보 상태, 검색·과정 이동·발표·근로시간 지도 기능을 유지합니다.
- 원문 파일명·과거 기록의 교육·실습 표현은 역사적 기록으로 남습니다. 사이트 안내와 원천 내용을 일괄 치환하지 않았습니다.
- 기존 AGENTS.md·.github·.gitattributes와 설정 파일은 수정하지 않았습니다. 최신 사용자 요청의 이름·목적 변경은 README와 통합 검토 기록에 남겼습니다.

## 새 환경 검증과 한계

빌드, 자동 테스트, 단독 HTML 생성 및 모듈 구문 검사를 수행합니다. 개별 MD 839개와 8개 ZIP 구성 파일을 원천 바이트와 대조하며, HTTP 다운로드 응답과 원래 파일명 속성도 검사합니다. 최종 실행 로그·정확한 파일 목록과 해시는 변경 파일 패키지의 verification 및 manifests를 참조해 주세요.

브라우저에서는 데스크톱과 390px 폭의 동일 페이지 렌더링, 자료실·자료확인·검색·다크 모드·메뉴를 점검했습니다. 좁은 화면은 임시 iframe 검증 페이지로 CSS 폭을 확인한 것이며 실제 휴대폰 검증은 아닙니다. 검증용 페이지는 산출물에 포함하지 않습니다. 브라우저 자동화의 다운로드 완료 이벤트가 시간 초과되어 실제 브라우저 저장 완료까지는 확인하지 못했습니다. 이를 HTTP 및 파일 무결성 검증과 구분합니다. 단독 preview.html의 실제 file:// 실행, 사용자 PC 적용, SAP 실행, Pages 배포는 미검증입니다.

## 적용 순서

1. 기존 프로젝트에서 AGENTS.md, `git status --short --branch`, `git diff`와 현재 HEAD를 확인하고 별도 수정은 백업합니다. 이 환경에서 확인한 원격 main과 패키지 기준은 `c9c22ea4a8aeb3d2ebc128948794099359c001a1`이며 사용자 PC 상태는 알 수 없습니다.
2. 변경 파일 ZIP은 별도 폴더에 풉니다. `CHECK_LOCAL_CHANGES.py`에 기존 저장소의 절대 경로를 전달하면 기준본·수정본·충돌·누락을 읽기 전용으로 비교합니다. 파일을 복사하거나 Git을 변경하는 기능은 없습니다.
3. 보고서·diff·검사 결과를 확인하고 `project/` 안의 변경 파일을 같은 상대 경로로 반영합니다. 충돌 파일은 비교·병합합니다. `.git`, `.github`, 기존 지침, 로컬 설정, 원천, 사용자 별도 수정 전체를 덮어쓰지 마세요.
4. Node.js 24 이상에서 `npm run build`, `npm test`, `npm run preview:file`을 실행합니다. `npm start`로 확인하거나 `preview.html`을 로컬에서 열어 검토합니다. 미리보기 HTML은 자료를 내장하므로 약 100MB이며 초기 로딩 시간이 걸릴 수 있습니다.
5. 홈과 하단의 v1.12.0, 각 소스의 MD 수, 핵심 MD 공백과 메뉴 변경을 확인합니다. 이후 사용자가 직접 커밋·push하고 운영 화면을 확인합니다.

전체 프로젝트 ZIP은 독립된 사본으로 검토·실행할 때 사용합니다. 기존 Git 저장소에 전체 ZIP을 덮어씌우는 용도로 권하지 않습니다. 이전 10월 18일 index.lock 오류에 대한 삭제·재커밋 작업은 수행하지 않았습니다.
