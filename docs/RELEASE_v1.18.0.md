# v1.18.0 · 설명 문체와 핵심 학습 대화 개편

수정일: 2026-10-28. 기준: v1.17.1 Full ZIP.

## 변경 내용

16개 과정과 6개 사례 도입부를 합니다체로 다듬고 문제·원인·선택·결과가 이어지도록 문단을 재구성했습니다. 서로 다른 내용은 문단을 나눴습니다. 소제목과 학습 흐름은 명사형으로 정리하고, 번호가 있는 절 제목의 콜론 뒤 설명은 제거했습니다.

편집 실수의 해명과 자료 미확보·미구현·반복 검증 안내는 학습 설명에서 제거했습니다. 실제 진단 값과 코드·당시의 핵심 시행착오는 보존하며, 설계나 모의 예제를 운영 완료로 바꾸지 않았습니다.

본문의 중요한 굵은 문장에는 짙은 파란색을 적용했습니다. 다크 모드에는 밝은 파란색을 사용합니다. 05·06·07 파일 관계도는 파일명을 누르면 MD를 직접 다운로드하고, 화살표와 밑줄을 표시하지 않습니다. 원래 파일명과 정확한 경로를 유지합니다.

## 프로젝트 대화

- 원본 메시지 위치 1,327개, 원본 에피소드 147개를 보존합니다.
- 학습 화면에는 핵심 대화 1,064개, 에피소드 134개를 표시합니다.
- 메시지 246개를 명시적으로 검토해 반복·감사·자료 이관 등 표시 제외 사유를 기록했습니다. 본문이 없는 자리와 단순 진행 안내도 화면에서 제외합니다.
- 사용자 요청 206개를 추가로 다듬었습니다. 전체 사용자 표시 문장 572개와 원문을 분리합니다.
- AI 응답 57개에서는 반복 상태 안내를 덜어낸 표시용 문장을 사용합니다.
- 147개 에피소드의 제목·목표·해설·결과를 정리했습니다. 내용이 비는 에피소드는 숨기고 이전 주소는 같은 프로젝트의 유효한 에피소드로 연결합니다.
- 제외 대화에 연결됐던 실제 첨부도 관련자료의 ‘프로젝트 첨부파일’ 목록에서 접근할 수 있습니다.

`content/conversations/reading-edition.json`에 제외 ID·사유·원문 해시와 표시용 편집을 저장합니다. 원본 해시가 바뀌면 빌드를 중단하도록 했습니다. 검색·집계·구성도·이전 다음 이동은 같은 선별 목록을 사용합니다.

## 검증

Node.js 24에서 build·preview:file을 완료했고 자동 검사 100개가 통과했습니다. 관계도 25개 다운로드 링크의 원본 바이트·저장 이름, 모든 공개 자료 경로, 16개 과정의 제목·근거 링크와 대화 이동을 검사했습니다. 원천·첨부 등 보호 대상 1,687개 파일의 바이트가 기준 ZIP과 같습니다. 과정의 실행 코드와 이미지도 보존했습니다.

브라우저에서 관계도 링크·화살표 제거·밑줄 제거, 라이트·다크 강조 색상, 명사형 학습 흐름, 해설 문단과 첨부 목록을 확인했습니다. 클라우드 브라우저의 다운로드 이벤트 반환은 시간 초과가 발생했으며, 다운로드 속성·로컬 HTTP 응답·Content-Disposition·원본 바이트 일치는 자동 검사로 확인했습니다. 상세 기록과 화면은 `docs/validation/v1.18.0/`에 있습니다.

## 로컬 적용

기준은 v1.17.1이며 삭제 파일은 없습니다. Changes ZIP의 project/를 같은 경로에 비교·병합합니다. 로컬 수정은 보존하고 파일별 전후 SHA-256은 CHANGE_MANIFEST.json에서 확인합니다. REVIEW.patch는 텍스트 변경을 검토할 때 사용합니다.

Full ZIP에는 전체 프로젝트 소스가 있습니다. 생성물인 dist/, preview.html, preview-data/는 포함하지 않으며 `npm run build`, `npm run preview:file`, `npm test`로 생성·검증합니다. GitHub 커밋·push·배포는 이 작업 환경에서 수행하지 않았습니다. APPLY.md에 Codex Desktop용 프롬프트를 제공합니다.
