# v1.10.1 변경 및 검증

## 반영

- 프로젝트 대화: 기존 확보 전문을 표시합니다. MCP M008의 구버전 요약이 남지 않도록 루트 진입점을 최신 dist로 연결했습니다. 긴 최종 AI 답변은 기본으로 펼치며, 실제 진행 안내는 별도로 접습니다. 다음 대화는 사용자 요청과 이어지는 AI 응답까지 표시합니다.
- 카카오 자료 정리: 진행 안내 5개를 구분하고 kwc-e02에 이어지는 최종 답변 kwc-m009까지 연결했습니다.
- 홈 제목: 홈 진입·재방문 시 타이핑을 다시 재생합니다. 숨겨진 탭에서는 일시 정지하고 활성화 시 이어갑니다. OS 모션 감소 설정은 유지합니다.
- 올리브 나무: 기존 7개 열매를 라이트에서는 올리브색, 다크에서는 붉은색으로 채색했습니다. 기존 PNG 바이트와 23개 모니터 모션을 유지합니다.
- GitHub Pages: 루트 index.html이 최신 dist/로 이동하며 대화 해시 주소와 검색 문자열을 보존합니다. 파일로 열면 preview.html로 이동합니다.
