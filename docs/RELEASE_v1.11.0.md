# v1.11.0 · WEBGUI 보완과 ESS 사례 추가

기준: 2026-10-16. v1.10.1 교육 포털 사본에서 변경했습니다. 사용자의 현재 PC 또는 GitHub 저장소는 수정하지 않았습니다.

## 변경 내용

- 과정 10 「WEBGUI 개선과 검증」에 Modern V1·V2와 ITS 비교·반영 도구 검토 대화 14개 항목, 에피소드 4개를 추가했습니다. 기존 Chrome v3 자료는 유지합니다.
- 과정 13 「ESS 근태시스템 개편」과 사례 실습 탭·메인 사례 카드를 추가했습니다. 4개 대화방의 508개 위치를 26개 에피소드에 연결했습니다.
- 전체 학습흐름은 7개 프로젝트, 89개 에피소드, 929개 위치입니다. 원문 전사 915개와 본문 없는 위치 14개를 구분합니다.
- 이번 추가 범위는 사용자 요청 261개·AI 본문 252개·AI 본문 없는 위치 9개입니다. 본문 없는 위치를 재구성하지 않았습니다.
- 원문 JSON·Markdown과 교육용 경어체를 분리합니다. 코드 블록은 표시 편집에서도 보존합니다.
- 기존 업무지도 말풍선 이동·문서 새 창 읽기, 제목 타이핑 효과, 테마별 올리브 열매와 기존 과정 주소를 보존합니다.

## 자료 보존과 한계

공유 화면에서 표시된 대화의 본문을 순서대로 전사했습니다. 플랫폼 전체 export, 공유 링크 밖의 분기·대화와 개별 발화의 정확한 시각은 포함하지 않습니다. DOM의 겹치는 발화 순서로 전사 구간의 연속성을 확인했습니다.

이번에 새로 확보한 이미지 74개와 ZIP 3개를 실제 파일로 열어 검증한 뒤 공개 다운로드에 연결했습니다. 첨부 이름·발화 위치는 확보 여부와 관계없이 기록합니다. 대형 KBS_WebGUI_Modern_v2.zip은 두 차례 내려받은 파일이 유효한 ZIP이 아니어서 포함하지 않았습니다. 대신 정상 검증된 SE80_WebGUI_V2_112files.zip과 SE80_CSS_21files.zip을 제공합니다. ESS 최종 SUBMIT_PRG01 ZIP을 포함했습니다.

화면 이미지 일부와 기타 개별 첨부는 다운로드 실패·파일 미전달·원본 미확보 상태입니다. 이 ZIP을 대화에서 언급된 모든 첨부의 완전한 원본 묶음으로 보지 않습니다. 각 프로젝트의 attachment-inventory.json과 자료 탭에서 항목별 상태를 확인할 수 있습니다.

기존 sources 파일 1,206개는 SHA-256 및 바이트 수를 대조해 보존했습니다. 새 자료는 sources/conversations/20261016-business/ 아래에 추가했으며 docs/source-files.json에 해시를 기록합니다. 원천 파일에 줄바꿈 변환을 실행하지 않았습니다.

## 검증 범위

교육 포털의 빌드·Node 테스트·로컬 미리보기와 자료 연결을 검증합니다. 원 대화의 SAP 수정안·운영 서버·휴가 데이터 처리 결과를 새로 실행 검증하는 작업은 아닙니다. ESS 마지막 SUBMIT_PRG01 이후의 사용자 재시험은 공유 대화에 없습니다. WEBGUI ITS 저장·활성화 도구는 검토 단계입니다.

## 로컬 적용

1. 기존 C:\ERP_EDU를 백업하고 AGENTS.md 및 `git status --short`를 확인합니다.
2. ZIP은 별도 폴더에 풉니다. ZIP 안 `erp-ai-portal`이 프로젝트 루트입니다.
3. .git, .github, 기존 AGENTS.md, .env와 로컬 설정·별도 수정은 보존합니다. 폴더 전체 삭제 또는 `/MIR` 동기화는 사용하지 않습니다.
4. content, site, scripts, tests, assets, sources의 변경과 package.json, docs, dist, preview.html, 루트 index.html을 비교하여 병합합니다. 기존에 별도 수정한 파일은 이 ZIP으로 무조건 덮어쓰지 않습니다.
5. 원천 자료는 바이트 그대로 복사하고 .gitattributes의 `sources/** -text`를 유지합니다. 이번 ZIP에 없는 로컬 파일을 삭제하지 않습니다.
6. Node.js 24 이상에서 `npm run build`, `npm test`, `npm run preview:file`을 실행합니다. 루트 index.html은 HTTP에서 최신 dist로, 파일 열기에서는 preview.html로 연결합니다.
7. 변경 차이와 실행 결과를 검토한 뒤 사용자가 직접 커밋·push합니다.

이 릴리스는 GitHub push·배포·SAP 반영을 수행하지 않습니다.
