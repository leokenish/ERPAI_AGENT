# 교육 대화 통합 기록

2026-10-13 · 포털 v1.7.1

## 화면에서 읽는 방법

1. 전체 구성도의 SAP·Export를 선택하면 최초 목적과 환경 확인 또는 첫 추출기 제작부터 읽는다.
2. GitHub·Codex·업무 지식·DIAG·피드백 등 다른 요소는 해당 학습 흐름으로 바로 연결된다.
3. 대화 기록에서 요청·응답을 순서대로 읽고, 긴 항목은 전문 펼치기로 확인한다. 다음 대화/전체 대화 펼치기로 이어 읽는다.
4. 해설·시행착오, 따라 하기, 프로젝트 맥락, 관련 자료에서 교육용 설명과 원천 근거를 구분한다.
5. 왼쪽 프로젝트 대화 메뉴에서는 구성도 필터 없이 6개 프로젝트를 탐색한다. 제목·요청·AI 본문은 전체 검색에 포함된다.

## 소스 추출 학습 흐름

초기 27개 대화쌍을 다음 네 단계로 추가했다. 이어지는 E01~E18은 기존 주소를 유지하며 실제 요청 뒤에 대응 AI 응답을 연결했다.

| 새 에피소드 | 공유 대화 번호 | 학습 내용 |
|---|---|---|
| E00-start | 1–4 | 시작 목적·SAP 환경·최초 진단 |
| E00-export | 5–14 | 첫 추출기·언어·함수 소스·내부 INCLUDE |
| E00-web | 15–23 | 다른 패키지·BSP/MIME·BASIS 700 오류·범위 |
| E00-context | 24–27 | 맥락 문서·파일명·언어 정책·인코딩 |

최초의 Import·활성화 목표는 E16에서 읽기 전용 DIAG로 바뀐다. 과거의 구현 제안을 현재 운영 기능으로 승격하지 않는다. 현재 확보한 Export 0.3.18·DIAG 0.4.5 파일과 실제 SAP 실행 성공은 별도다.

## 통합과 보존 규칙

- 새 공유 추출물: sources/conversations/20261013-shared/kbs-erp-export-diag-agents. ZIP 내부 파일을 바이트 그대로 보존했다.
- 이전 추출물: sources/conversations/20261012 및 20261012-supplement. 원문·첨부·해시를 수정하지 않았다.
- 게시용 전문과 학습 해설: content/conversations/export-full. 원래 SHARE 식별자와 플랫폼 발화 ID, 순서, 본문, 미확인 시각을 보존한다. 교육 해설과 실습은 별도 필드다.
- content/conversations/catalog.json의 sourcePath가 게시 데이터를 선택하고 assetSourcePath는 이전에 확보한 첨부 위치를 가리킨다. 첨부를 중복 복사하거나 새로운 다운로드로 꾸미지 않는다.
- content/conversations/editorial-prompts.json: 사용자 문장만 정중한 교육용 문장으로 다듬으며 원문 SHA-256으로 연결한다. AI 본문은 편집하지 않는다. 원문 확인·원문 복사 UI는 다시 추가하지 않았다.
- 게시 순서는 공유 화면을 기준으로 한다. 이전 U030/U031 중복 요청은 같은 공유 요청을 가리켜 한 번만 표시한다. 이전에 수록됐던 별도 진행 안내는 보존 원천에 남기며 공유 경로에 임의 삽입하지 않는다.
- content_type=unavailable은 빈 assistant 본문과 no_response_body_visible 상태를 함께 요구한다. 화면에는 별도의 중립 안내 상자로 렌더링한다.
- 모든 항목은 적어도 하나의 학습 에피소드에서 접근 가능하며, 요청과 대응 응답 위치는 같은 에피소드에 연결한다.

관련 자료에서 프로젝트 맥락·학습 가이드·대화 JSON·전문 MD·본문 없는 위치 목록을 받을 수 있다. 원천 HTML과 실행 코드를 통째로 웹에 게시하지 않으며, 표시용 Markdown은 기존 안전한 렌더러를 사용한다. 과거 sandbox 링크와 미확보 상대 경로는 가짜 다운로드를 만들지 않는다.

## 갱신과 검증

일반 운영은 Node.js의 npm run build, npm test, npm run preview:file로 충분하다. scripts/integrate-shared-conversation.py는 이번 자료를 편집 데이터로 구성한 재현용 도구이며 일반 빌드에 Python을 추가하지 않았다.

32개 자동 검증으로 원문 보존·전체 참조·58개 에피소드의 5개 탭·구성도 진입·복사·검색·첨부·다운로드·발표·테마를 확인했다. UI 이동 로직은 DOM 대역 검증이며 실제 브라우저의 줄바꿈·모바일·Safari 렌더링은 이 환경에서 확인하지 못했다. 자세한 범위는 VALIDATION.md에 있다.

이전 통합 상태와 당시의 “미확보” 설명은 history/CONVERSATION_INTEGRATION_v1.7.0.md에 이력으로 남겼다.
