# v1.11.1 · 대표 숫자 카운트 효과와 학습 대화 문체 보완

2026-10-17. v1.11.0 ZIP을 기준으로 수정했습니다. 사용자 PC의 C:\ERP_EDU와 GitHub는 변경하지 않았습니다.

## 변경 사항

- 홈의 프로젝트·에피소드·교육 과정 수, 과정 목록의 총 과정 수, 사례·확장 설계 개수, 프로젝트 대화의 주요 통계, 업무지도의 문서·지도·링크 수에 카운트 효과를 추가했습니다.
- 숫자가 화면에 처음 들어오면 0부터 약 1.6초 동안 빠르게 증가한 뒤 서서히 감속하여 정확한 최종값에서 멈춥니다. 같은 화면에서는 스크롤만으로 반복하지 않으며, 화면을 새로 방문하면 다시 재생합니다.
- 천 단위 구분과 기존 두 자리 숫자 표기를 유지합니다. 최종 숫자 폭을 미리 확보하여 글자 위치가 흔들리지 않도록 했습니다.
- 동작 줄이기 설정과 인쇄에서는 최종값을 바로 표시합니다. 접근성용 숫자는 항상 최종값이며, 화면을 떠날 때 프레임·이벤트·관찰자를 정리합니다. 숨긴 탭에서는 멈추었다가 이어갑니다.
- 최근 WEBGUI·ESS를 포함하여 표시용 사용자 발화 186개와 AI 응답 77개를 추가로 다듬었습니다. 요청은 자연스러운 주세요/마세요 체, 설명은 입니다/하겠습니다 체로 정리했습니다. 질문·성공 보고·미확인 상태의 의미와 시제를 유지했습니다.
- 과거 답변 인용, 실행 코드, 파일·객체 식별자와 첨부는 보존합니다. 이미 적절한 경어체인 본문과 구조화된 제목·표의 짧은 항목은 불필요하게 늘리지 않았습니다.
- 표시용 수정은 editorial-prompts.json과 editorial-responses.json에서 관리합니다. 원문 JSON, Markdown, 확보 수준, 발화 순서와 첨부는 변경하지 않았습니다. 검색과 표시 문장 복사에도 편집 문장을 사용합니다.

## 유지하는 내용

전체 13개 과정, 7개 대화 프로젝트, 89개 에피소드, 929개 대화 위치(915개 전사·14개 본문 미확보)를 유지합니다. 업무지도 말풍선 이동·본문 별도 창, 메인 제목 타이핑, 테마별 올리브 열매 7개와 기존 디자인을 보존합니다. ‘WEBGUI 개선과 검증’과 ‘ESS 근태시스템 개편’의 사례·운영 항목도 유지합니다.

새 공유 대화를 수집하거나 기존 미확보 답변·첨부를 만들어 넣지 않았습니다. 원천 파일의 바이트·줄바꿈과 docs/source-files.json의 기존 보존 해시는 변경하지 않았습니다.

## 적용 방법

1. C:\ERP_EDU의 AGENTS.md와 `git status --short`를 먼저 확인하고 별도 수정 사항을 백업합니다.
2. ZIP을 별도 폴더에 풀고, 안의 erp-ai-portal을 기존 프로젝트와 비교하여 병합합니다. .git, .github, AGENTS.md, .env, 로컬 설정과 별도 변경은 보존합니다. 폴더 삭제나 미러 동기화는 사용하지 않습니다.
3. site, content, scripts, tests, package.json, docs와 생성된 dist, preview.html, 루트 index.html을 함께 반영합니다. sources와 첨부는 v1.11.0과 동일하므로 기존 파일을 재저장하거나 줄바꿈 변환하지 않습니다.
4. Node.js 24 이상에서 `npm run build`, `npm test`, `npm run preview:file`을 실행합니다. 로컬 파일 열기는 preview.html을 사용합니다. HTTP의 루트 index.html은 최신 dist로 연결합니다.
5. 실제 화면을 확인한 후 사용자가 직접 commit·push합니다.
