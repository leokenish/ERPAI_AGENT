# v1.16.2 — 사이트 전체 설명문 문체 정리

문체 정리일: 2026-10-27 KST. 자료 기준일은 기존 2026-10-26을 유지한다.

## 요청과 반영

사용자가 승인한 근로시간 사례의 문체를 사이트 전체 설명에 적용했다. 내용·구성을 바꾸거나 지우지 않고, 충분한 배경과 이유를 담은 자연스러운 평서문으로 정리했다. 긴 문장 안의 상황·판단·결과를 나눴으며, 설명을 키워드나 짧은 항목만으로 줄이지 않았다.

| 범위 | 이번 반영 |
|---|---|
| 과정 01–16 | 본문 16개와 활용사례 도입부 6개를 문단별로 교정 |
| 설명형 소제목 | 46곳의 의미와 순서를 유지하며 종결어미 정리 |
| 홈·전체 과정·구성도 | 소개·요약·역할 설명을 같은 문체로 정리 |
| 사례 상단 | Insight·Intent·Spec·Plan 24개 요약과 갤러리·기능 설명 정리 |
| 자료실·업무지도 | 핵심 MD 113개 용도, 분류 설명, 역할과 탐색 안내 정리 |
| 프로젝트 대화 | 9개 프로젝트·147개 에피소드 검토. 목표·준비물·해설·결과·관련자료 설명 등 604곳 교정 |
| 전체 설명 필드·UI 문자열 | 907곳 교정. 본문 22개 파일의 교정은 별도 집계 |

과정 본문·도입부의 전체 글자 수는 80,880자에서 80,968자로 바뀌었다. 분량을 요약하는 편집이 아니다. 이미 자연스러운 평서문, 짧은 제목·레이블, 실제 발화와 조작 안내는 문맥에 맞게 유지했다.

## 보존한 내용과 구성

- 16개 과정 번호·공식 제목·분류·순서와 주소를 유지했다.
- 본문 22개 파일의 제목 단계, 문단 블록, 목록 항목·순서, 표의 행·열, 코드 블록, 인라인 코드, 인용문, 수치·날짜·버전, 링크와 이미지 목적지를 대조했다.
- 기존 목차의 `section-N`과 `context-section-N` 주소를 유지했다.
- 9개 프로젝트, 147개 에피소드, 1,327개 대화 항목의 실제 발화·역할·시각·순서·확보 수준·첨부 연결을 보존했다. 사용자·AI 표시용 발화 편집본도 그대로다.
- 원천 1,576개 파일, 기존 이미지 자산 36개, 예제 5개와 AGENTS·GitHub 설정·vendor의 바이트가 기준 ZIP과 같다. 근로시간 783개 MD와 문서 관계도 같다.
- 867개 소스 MD와 핵심 MD 분류·개별 다운로드 경로·해시를 유지했다. 자료실의 용도 설명을 고쳤으며 프로젝트 원본 MD를 새 문체로 덮어쓰지 않았다.
- CSS·페이지 배치·메뉴·탭·갤러리·지도·다운로드·검색 동작은 바꾸지 않았다. 기존 테스트 한 곳의 고정 문구 기대값만 새 표시 문장에 맞췄다.
- 삭제 파일은 0개다. ‘이 과정 자료’와 발표 기능도 다시 추가하지 않았다.
