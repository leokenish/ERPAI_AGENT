## 진행 상태를 읽을 때의 구분

- **추출·진단:** 최신 소스는 Export 0.4.1 / DIAG 0.7.1입니다. 사용자가 SAP 성공을 확인한 것은 0.6.11의 기존 미활성본 재사용·단일 BSP 활성화·SE80 확인입니다. 최신 0.7.1 전체 검증으로 확대하지 않습니다.
- **WEBGUI:** 특정 결재 화면과 한 메뉴의 다운로드 성공 보고가 있습니다. 최신 V429의 SAP 재시험·최종 수용은 미확인입니다.
- **ESS:** 마지막 SUBMIT_PRG01 뒤의 적용·재시험 결과는 해당 공유 대화에 없습니다. 기존 성공 보고의 범위를 유지했습니다.
- **타임라인:** UI 2.3·HML 617개 처리 보고와, 전 기간 의미 연결 정확도·최종 UI 수용은 별개입니다. 5주 표본을 전체 자료 검증으로 표시하지 않습니다.
- **스마트 ERP:** v9 프리뷰·문서는 확보했지만 보관된 전체 ZIP은 정상 해제되지 않습니다. 65,789,905 bytes와 SHA256 `e1bfbb458caa87455e482409e94cf2b7901ebc0466b5e88100377d3ebd33a08f`를 대조하고 압축 오류를 재확인했습니다. 이를 정상 반영 패키지로 게시하지 않았으며, 다음 과제는 전달 패키지 정상화와 SAP 검증입니다.

- 기존 원본·자산·설정 1,357개 파일: 누락·바이트 변경 없음.
