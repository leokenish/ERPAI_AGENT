## 파일 구성과 로컬 반영

전체 ZIP에는 16개 과정·원천 자료·첨부·화면 코드·빌드 스크립트·폰트·최종 삽화가 들어 있습니다. ZIP의 `project/` 안이 기존 저장소 루트에 대응합니다.

1. ZIP은 기존 저장소 밖에서 압축을 풉니다.
2. 로컬이 v1.18.1이면 Changes ZIP으로 변경분을 반영합니다. 더 이전 버전이거나 전체 소스가 필요하면 Full ZIP을 사용합니다.
3. `CHANGE_MANIFEST.json`의 변경 전·후 해시와 `REVIEW.patch`를 기준으로 로컬 파일을 비교·병합합니다. 로컬 수정이 다르면 무조건 덮어쓰지 않습니다.
4. `.git`, 원격·브랜치 설정과 사용자의 별도 수정을 보존합니다. 이번 버전의 삭제 파일은 없습니다.
5. Node.js 24 이상에서 아래 명령을 순서대로 실행합니다.

```bash
npm run build
npm run preview:file
npm test
npm start
```

6. 05 과정의 삽화 위치·원본 확대·화면 이동을 확인한 뒤 소스 변경만 커밋하고 기존 원격·브랜치로 push합니다.

`dist/`, `preview.html`, `preview-data/`, `node_modules/`는 재생성 결과물이므로 소스 ZIP에 중복 포함하지 않습니다. 로컬 빌드로 다시 만들며 새로 Git 추적에 넣지 않습니다. 전체 소스에 기존 자료와 최종 삽화가 모두 포함되어 있어 빌드에 별도 이미지 다운로드가 필요하지 않습니다.

ZIP의 `APPLY.md`에는 Codex Desktop에 그대로 붙여 넣을 로컬 반영·검증·GitHub push 프롬프트가 있습니다.

이번 작업에서는 패키지 제작까지만 수행했으며 사용자 PC·GitHub 원격·운영 사이트는 변경하지 않았습니다.
