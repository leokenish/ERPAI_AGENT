- 데스크톱 브라우저에서 GITHUB/CODEX 분리, 검색 결과와 이동, 새 자료확인 목록·검색, 홈 사례 카드, 핵심 MD 도착점과 라이트·다크 표시를 확인했습니다.

## 적용 방법

원격 저장소는 `leokenish/ERPAI_AGENT`이며 이번 확인 시 main은 `b7e4c406781669d96bad03668b9c95bf03a009e1`입니다. 해당 커밋의 AGENTS.md, content/catalog.json, site/app.js, scripts/build-source-documents.mjs가 로컬 v1.12.0 기준과 같은 Git blob임을 확인했습니다. 원격 전체 트리 또는 사용자 PC의 미커밋 변경까지 같다고 보증하지 않습니다.

1. 기존 저장소의 AGENTS.md, HEAD, `git status --short --branch`, `git diff`를 확인하고 별도 수정은 보존합니다.
2. 변경 파일 ZIP을 별도 폴더에 풉니다. `python3 CHECK_LOCAL_CHANGES.py /기존/프로젝트/경로`로 적용 대상 파일을 읽기 전용 비교합니다. 이 스크립트는 복사·삭제·Git 변경을 하지 않습니다.
3. 충돌이 없는지 검토하고 `project/` 안의 파일만 동일 상대 경로로 반영합니다. 충돌 표시 파일은 전후 diff와 비교해 병합합니다. .git·로컬 설정·사용자 별도 수정에 전체 ZIP을 덮어씌우지 않습니다.
4. Node.js 24 이상에서 `npm run build`, `npm test`, `npm run preview:file`을 실행합니다. `npm start`로 화면을 확인합니다. preview.html은 자산을 내장한 약 100MB 파일이므로 로딩 시간이 걸릴 수 있습니다.
5. 버전 v1.13.0, 03-A/B, 14개 과정, 자료실 24/8/15개와 네 문서 다운로드, 사례 카드 4개를 확인합니다. 커밋·push·운영 반영은 검토 후 진행합니다.

전체 ZIP은 별도 사본으로 실행·검토할 때 사용합니다. 변경 ZIP에는 기준본에 없는 파일과 바뀐 파일만 포함합니다.
