# ERP AI 에이전트 v1.16.1 — 활용사례의 시작과 구현 맥락 추가

작성일: 2026-10-26 (Asia/Seoul)

## 반영 내용

활용사례 11–16에 **이유 → 실제 근거·시행착오 → 방향 설정 → 기술적 구현**의 도입 설명을 각각 추가했습니다. 기존 사례를 다시 쓰지 않고, 프로젝트의 네 가지 관점 요약 다음에 새 설명을 읽고 기존 지도·화면·본문으로 이어지도록 구성했습니다.

| 과정 | 추가한 맥락 |
|---|---|
| 11 근로시간 AI 에이전트 구축 | 코드만으로 설명하기 어려운 입력·협의 배경, 실제 오판과 정정, 지식·스킬·지도·피드백의 역할과 질문 처리 흐름 |
| 12 ERP WEBGUI 개편 | 공통 화면 개선 동기, 아이콘 의미와 다운로드 원인의 시행착오, 기존 명령 보존, 문서 수집·표시·반영의 연결 |
| 13 ERP AI 에이전트 포털 구축 | 동료에게 판단 과정을 전달하려는 목적, 자료 증가와 학습 흐름의 문제, 원문·설명 분리, 빌드·검증·변경분 전달 |
| 14 ESS 근태시스템 개편 | 부분 날짜 변경의 부담, 현재 소스·상신 표시와 실제 결재의 차이, R1 분리, 입력부터 승인·잔여 일수까지의 경로 |
| 15 업무일지 타임라인 개발 | 제출한 보고의 재활용, 실제 HML·수집·표시 오류, 관측과 추론·파일 역할 분리, 업무카드·색인·타임라인 갱신 |
| 16 스마트 ERP 메인화면 개편 | 기존 업무와 첫 화면 개선, 시안·창 크기·국소 이미지 보정의 시행착오, 기능·최종 시안 보존, BSP·iframe·표현 계층 |

추가 문서는 `content/lesson-contexts/`에 있으며 `content/catalog.json`의 `contextFile`로 연결합니다. 새 설명도 목차·검색·오프라인 미리보기에 포함합니다. `context-section-N`을 사용하여 기존 `section-N` 목차 주소는 그대로 유지합니다.

## 보존한 요소

- **기존 16개 과정 본문 파일 전부 바이트 동일** — 직전 01–10 개편과 11–16 본문·실습·한계 설명을 모두 보존합니다.
- 원천 1,576개, 대화·문체 편집 68개, assets 36개 파일을 기준 ZIP과 바이트 대조했습니다.
- 기존 4MD 요약, 갤러리·기능 전환·아이콘 비교, 문서 지도, 자료실·다운로드, 실제 대화, 이전/다음 이동을 유지합니다.
- 카탈로그는 버전과 여섯 `contextFile` 속성만 변경했습니다. 기존 번호·명칭·주소·소개·4MD·갤러리·자료 목록은 동일합니다.
- ‘이 과정 자료’ 박스와 발표 기능은 재도입하지 않았습니다. 원천 MD와 실제 대화를 새 해설로 덮어쓰지 않았습니다.

근거와 서술 범위는 `docs/CASE_CONTEXT_v1.16.1.md`에 있습니다. 특정 사용자 성공·당시 프리뷰·모의 처리·문서 검사와 실제 SAP 운영 검증을 구분합니다. 이번에 원 프로젝트의 프로그램을 실행한 것은 아닙니다.

## 검증

- `npm run build` 성공.
- `npm run preview:file` 성공. 오프라인 생성·복원 검사를 수행했으며 실제 `file://` 브라우저 실행은 수행하지 않았습니다.
- `npm test`: **90개 통과, 실패·생략 0개**. 기존 89개 검사에 새 설명의 표시 순서·기존 요소·목차·검색·직접 주소 이동을 확인하는 검사를 추가했습니다.
- 실제 데스크톱 브라우저에서 11–16의 네 절, 4MD 요약, 기존 본문과 목차를 확인했습니다. 1348px 화면에서 가로 넘침이 없습니다.
- WEBGUI의 기존 갤러리와 다운로드 기능 설명 전환, 추가 설명의 목차 이동과 직접 주소, 새 문구 검색 결과를 확인했습니다.
- 390px 테스트 프레임에서 타임라인의 새 설명을 라이트·다크로 확인했습니다. 본문 폭·스크롤 폭은 375px로 가로 넘침이 없습니다. 실제 휴대전화 시험은 아닙니다.
- 화면 확인용 임시 파일은 전달 패키지에서 제외했습니다. 실행 로그와 보존 결과는 `docs/validation/v1.16.1/`에 있습니다.

사용자 PC·GitHub 원격·실제 SAP는 이번에 접근하지 않았습니다. 커밋·push·운영 배포는 수행하지 않았습니다.
