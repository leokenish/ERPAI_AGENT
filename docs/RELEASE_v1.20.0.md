# v1.20.0 · 근로시간 시스템 고도화

## 추가 내용

- 17과정을 홈·좌측 메뉴·전체 과정·활용사례 구성도·검색에 추가했습니다.
- 7개 세부 사례를 업무 상황 → 실제 근거와 시행착오 → 방향 설정 → 코드 구현으로 설명합니다.
- 원천 293발화를 20개 에피소드로 연결하고, 프로젝트마다 한 명의 대역을 고정합니다. 관리용 도구 호출·중복 전달은 학습 화면에서 제외하되 원천은 보존합니다.
- 최팀장(휴휴/지급 항목 제외), 우대리(단가 점검), 이과장(정산 비교/등록 취소), 채주임(소급 표시), 오사원(반일 입력 안내)을 배정합니다. AI는 기존 ChatGPT 로고를 사용합니다.
- 시각자료 7개를 추가합니다. 단가 검사·소급 차액·두 삭제 업무의 조건은 입력을 바꿔 볼 수 있습니다.
- 첨부 HTML 7개를 표시용으로 정리하고 원본은 별도로 보존합니다. 코드 비교·복사 동작을 외부 스크립트로 분리하여 기존 CSP를 유지합니다.
- 자료실 소스 11과 MD 38개(진행문서 4개, 세부 가이드 7개, 실제 지식·피드백 27개), 대화별 ABAP 12개와 실제 이미지 5개를 연결합니다.

## 보존 원칙

원천 424개 파일은 SHA256 목록으로 바이트 일치를 검증합니다. 원문 발췌 MD를 새 다운로드로 공개하지 않습니다. 기존 01~16과정과 기존 프로젝트의 대역은 유지합니다.

과정 설명은 현재 비교 도구와 후속 설계를 구분합니다. 토6/일2의 금액 예시는 해당 조건의 예시이며 모든 휴휴 사례에 적용하지 않습니다. 소급 표시와 실제 확정 저장, 지급 항목 제외와 선택근무 등록 취소를 별도로 설명합니다. SAP 운영 반영을 대신 수행하는 사이트가 아닙니다.

## 검증 범위

정적 빌드, 오프라인 미리보기 생성, 자동 회귀검사, 원천 해시·코드블록 보존, 계산 예시·삭제 조건, 브라우저의 과정·대화·보고서 UI를 검증합니다. 업로드한 ABAP의 SAP 실행을 이 포털 편집 작업에서 수행하지는 않았습니다.

검증 결과: `npm run build`, `npm run preview:file` 성공, 자동 테스트 124/124 통과. 브라우저에서 7개 보고서 로딩, 휴휴 보고서 구간 필터·코드 복사, 단가 공배수 판정, 소급 상계, 전표 존재 시 지급 제외 중단, 채주임/ChatGPT 대화 표시를 확인했습니다.
