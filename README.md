## 로컬 실행

Node.js 24 이상에서 프로젝트 폴더를 열고 실행합니다. 일반 빌드는 외부 npm 의존성 설치가 필요 없습니다.

```bash
npm run build
npm start
```

터미널에 표시되는 주소를 브라우저에서 엽니다. 파일을 직접 여는 오프라인 미리보기가 필요하면 `npm run preview:file`을 실행하고 생성된 `preview.html`과 `preview-data/`를 함께 둡니다.

전체 검증:

```bash
npm run build
npm run preview:file
npm test
```

## 저장소와 배포

`site/`, `content/`, `sources/`, `assets/`, `scripts/`가 원본입니다. `dist/`, `preview.html`, `preview-data/`는 재생성 가능한 결과물로 Git 추적에서 제외합니다. 이미 추적하던 파일은 이번 변경 ZIP의 삭제 목록에 따라 추적을 해제해야 합니다. `.gitignore` 추가만으로 기존 추적 파일이 사라지지 않습니다.

GitHub Actions는 Node 24에서 소스를 빌드하고 `dist/`만 Pages에 게시합니다. 기존 `#/learn/...` 주소와 대화 주소를 유지합니다. 로컬 적용·검증 내역은 `docs/validation/v1.19.2/local-application.json`에 기록합니다.
