# ERP AI 에이전트 교육 포털

KBS ERP 담당 팀원을 위한 교육·실습·참고 포털입니다. 기존 6개 프로젝트 자료와 실제 대화에 ERP_AI의 MD 스냅샷을 연결하여 12개 교육 과정을 구성했습니다.

**v1.9.0 · 읽기와 이동 정리:** 코발트·퍼리윙클과 기존 일러스트를 유지하면서 페이지 제목·구역 제목·소제목, 본문·보조 글자의 공통 크기를 맞췄습니다. 과정·대화·자료·이동 영역을 부드러운 배경과 테두리로 구분합니다. 모든 과정 상단에 인쇄/PDF 저장과 교육 MD 다운로드를 배치하고 이전·다음에는 이동할 제목을 표시합니다. 학습 완료 버튼·체크·집계를 제거했으며 교육용 사용자 요청과 실습 예시를 ‘주세요/마세요’ 체로 정리했습니다. AI 응답과 추출 원문은 그대로 보존합니다.

**v1.8.2 · 지도 선택 고정:** 마우스를 올리면 해당 노드만 준비 상태로 강조합니다. 클릭하면 연결선·관련 문서·말풍선이 고정되고, 말풍선에서 MD 다운로드와 본문 읽기를 사용할 수 있습니다. 다른 노드 클릭은 선택을 바꾸며 빈 곳·지도 밖 클릭·닫기·Esc는 선택을 해제합니다. 확대·축소와 드래그 중에도 고정 상태를 유지합니다.

**v1.8.1 · 전체 문서 지도 개편:** 근로시간 MD 783개를 7개 색상 그룹의 작은 노드로 한 화면에 표시합니다. 마우스를 올리면 제목·경로 풍선이 나타나고 선택하면 전체 배치를 유지한 채 관련 링크를 강조합니다. 모든 개별 연결선, 검색, 확대·축소, 드래그, 지도 크게 보기와 본문·MD 다운로드를 제공합니다. 노드와 선을 같은 SVG 좌표에 배치하여 기존 카드 연결선의 어긋남을 제거했습니다. 원천·과정·대화·테마는 유지합니다.

**v1.8.0 · 근로시간 AI 에이전트 구축:** 과정 11을 추가하고 포털 갱신을 12로 이동했습니다. GitHub `leokenish/ERP_AI`의 커밋 `520ac77046f54d589bdcd49003ee41d0a803022f`에서 MD 783개만 확보했습니다. 7개 역할 분류, 23개 업무 지도, 실제 MD 링크 9,425개를 탐색하고 문서 내용·개별 다운로드·전체 MD ZIP을 확인할 수 있습니다. 소스 설명 MD 692개를 포함하되 ABAP·웹 자산은 읽거나 수집하지 않았습니다. 이후 갱신 방법은 `docs/WORKTIME_KNOWLEDGE.md`를 따릅니다.

**v1.7.1 · 공유 대화 전문 반영:** 소스 추출 프로젝트에 사용자 요청 119개·AI 응답 전문 116개를 연결하고, 본문이 표시되지 않은 응답 3곳은 별도 안내로 구분했습니다. 초기 목적·환경 확인, 첫 추출기, BSP·MIME, 맥락 문서의 4개 에피소드를 추가했습니다. 전체는 **6개 프로젝트·58개 에피소드·386개 항목(본문 383개, 본문 없음 안내 3개)**입니다. SAP·Export 구성도에서 시작 대화로 진입하며 기존 E01~E18 주소·첨부·디자인·발표 타이핑을 유지합니다.

**v1.7.0 · 대화 보완·발표 수업 확장:** 소스 추출·DIAG와 WebGUI 보완본을 연결해 총 54개 에피소드·249개 대화 항목을 제공합니다. 새 항목은 자료 추출 과정의 AI 응답 8개와 사용자 문의 1개이며, 과거 기술 답변 전문의 누락은 여전히 남아 있습니다. 발표 7개 화면에는 실무 순서·교육용 요청 예시·시행착오·확인 질문과 해설·실제 대화 링크를 추가했습니다. 페이지 진입 시 제목과 본문이 순서대로 타이핑되며 ‘전체 표시’로 즉시 읽을 수 있습니다. 모션 감소 설정에서는 완성된 글을 바로 표시합니다.

**v1.6.2 · 대화 화면 정리·화면 모션 유지:** 사용자 말풍선을 연한 로즈 베이지로 변경하고 AI 세이지색은 유지했습니다. 원문 확인·원문 복사 UI를 제거했으며 교육용 문장 복사는 유지합니다. 컴퓨터 화면의 데이터 페이드는 전역 동작 줄이기 정지 규칙에서 분리하여 계속 재생합니다. 제목·테마 전환은 기존 설정을 따릅니다. AI 답변 전문 보완 프롬프트는 `docs/AI_Response_Full_Export_Prompt.txt`에 있습니다.

**v1.6.1 · 교육 문체·말풍선 개선:** 텍스트가 있는 사용자 발화 143개를 정중한 교육용 문장으로 편집했습니다. 원문은 수정하지 않고 각 항목에서 별도로 확인·복사할 수 있습니다. 사용자 요청은 코발트, AI 응답은 세이지 계열로 구분하며 다크 모드도 함께 적용했습니다. AI 답변 원문 미확보·요약 구분은 유지합니다.

**v1.6.0 · 실제 프로젝트 대화 학습:** 새로 제공한 6개 대화 추출 ZIP의 54개 에피소드·240개 대화 항목·23개 화면을 연결했습니다. 전체 구성도의 요소를 선택하면 관련 프로젝트의 대화, 해설·시행착오, 따라 하기, 시작 맥락, 근거 자료를 읽을 수 있습니다. 왼쪽 ‘프로젝트 대화’ 메뉴에서는 전체 흐름을 탐색합니다. 원문 전사·발췌·요약과 미확보 답변을 구분합니다. 상세 기준은 `docs/CONVERSATION_INTEGRATION.md`에 있습니다.

**v1.5.5 · 홈 배경 조정:** 사례 실습은 세이지 그레이, 확장 설계는 따뜻한 스톤 그레이로 구분했습니다. 진한 파란 경계선을 제거하고 배경과 여백으로 연결합니다. 다크 모드는 각 색조의 짙은 중성 배경·카드·호버색을 사용합니다.

**v1.5.4 · 홈 학습 구성:** 세 방향 비교·실제 결과 읽기·WebGUI 타이머를 사례 실습 카드 3개로 배치했습니다. 아래에는 원격 자문·ERP/Telegram 과정 2개를 확장 설계 영역으로 구분했습니다. 큰 ERP AI 장식 문구는 제거하고 실제 푸터만 남겼습니다. 새 과정이 추가되어도 홈의 선별 카드가 자동으로 늘어나지는 않습니다.

**시작 위치:** 이 파일 → `docs/MAC_SETUP.md` → `docs/CONTENT_WORKFLOW.md`.

## 실행

Node.js 24 이상이 필요합니다. 포털 자체에는 npm 설치 의존성이 없습니다. Markdown 변환기 Marked 17.0.5를 MIT 라이선스와 함께 포함했습니다.

```bash
npm run build
npm test
npm start
```

브라우저에서 `http://127.0.0.1:8080`을 엽니다. Node.js가 이미 설치되어 있다면 위 명령만으로 시작할 수 있습니다. 운영용 dist/index.html을 Finder에서 직접 여는 방식은 지원하지 않습니다. 단독 검토본 preview.html은 직접 열 수 있습니다.

같은 사내망의 다른 PC에서 접근할 때:

```bash
npm run start:lan
```

이 명령은 `0.0.0.0:8080`으로 수신합니다. 팀원에게는 맥의 실제 사내 IP 또는 구성한 도메인을 알려줍니다. `0.0.0.0`은 배포 주소로 공유하지 않습니다.

- 12개 과정의 목차·본문·교육 MD 다운로드·인쇄
- 교육 제목·본문 검색, 분류별 과정 보기
- 근로시간 MD 783개: 역할·폴더·제목·경로·요약 검색, 연결 탐색, 본문 읽기와 다운로드
- 기본 작업 / 원격 협업 구성도와 요소별 설명·대화 기반 학습
- 프로젝트 대화 6개·에피소드 58개, 원문·해설·실습 전환, 복사·첨부 확대·직접 주소
- 교육 본문과 실제 대화 통합 검색
- 10개 합성 사례를 사용하는 DIAG 세 방향 비교 실습
- 실제 Obsidian 지도·DIAG 결과 캡처 확대와 카카오톡 → 업무지식 MD 사례
- 실제 진단 결과 해석과 WebGUI 타이머 모형 사례
- 7개 화면의 발표 모드: 목적·실무 순서·요청 예시·시행착오·확인 질문, 제목·본문 타이핑과 전체 표시, 방향키 이동
- 원천 프로젝트의 구현·검증 상태와 출처 위치
- 업무 근거·연결 문서·피드백 양식, 기존 중앙 MCP 예제
- 과정별 인쇄/PDF 저장·교육 MD 다운로드, 제목이 보이는 이전/다음 이동
- 반응형 메뉴, 키보드 탐색, 코드 복사, 이미지 확대

## 폴더

| 경로 | 역할 | 웹 배포 |
|---|---|---|
| sources/ | 제공 자료의 보존 사본 | 기본 제외. 과정 11에 지정한 ERP_AI MD만 downloads로 복사 |

| content/catalog.json | 제목·분류·상태·출처·발표 자료 | 빌드 데이터로 포함 |
| content/templates/ | 실습 양식 | catalog에 등록한 파일만 |
| assets/ | 교육 이미지·구성도 | 포함 |
| examples/ | 선별한 실습 자료 | catalog에 등록한 파일만 |
| site/ | HTML·CSS·JavaScript | 포함 |
| scripts/ | 빌드·정적 서버·맥 서비스 | 제외 |
| tests/ | 검증 | 제외 |
| vendor/ | 빌드용 Markdown 변환기와 라이선스 | 제외 |
| docs/ | 통합·운영·검증 안내 | 제외 |

이 ZIP에는 GitHub에 올릴 전체 프로젝트와 미리 빌드한 dist를 함께 제공합니다. `dist/`는 생성물이며 직접 편집하지 않습니다. 원본 작업은 content·site·assets에서 수행합니다.

## GitHub에 처음 올리기

사용할 저장소를 준비한 후 이 폴더의 내용을 올립니다. 원천 자료와 ABAP·검증 자료가 포함되어 있으므로 사내 허용 범위에 맞는 저장소를 선택합니다. 이 패키지는 원격 저장소 생성이나 push를 자동 실행하지 않습니다.

이미 만든 저장소를 클론한 경우, 이 폴더의 **내용**을 클론 폴더 루트에 넣고 검토 후 커밋합니다. 기존 AGENTS.md가 있다면 비교·병합하고 무조건 덮어쓰지 않습니다.

## 갱신

```bash
git status
git pull --ff-only
npm run build
npm test
```

정적 파일 갱신은 서버 재시작 없이 새 요청에 반영됩니다. 빌드가 dist를 교체하는 짧은 시간에 요청이 오면 실패할 수 있으므로 팀 사용이 적은 시간에 수행합니다. 무중단 배포가 필요하면 별도 배포 디렉터리와 원자적 전환을 구성합니다.

## 운영 경계

포털은 ERP, MCP, Telegram, 외부 AI를 호출하지 않습니다. 교육 웹서버에는 DB·토큰·로그인 기능이 없습니다. 중앙 자문 MCP 예제의 SQLite는 별도 프로그램의 요구사항입니다. 원격 예제는 다운로드 후 별도 환경에서 실행합니다.

이 환경에서 웹 기능과 Node.js 검증을 수행했습니다. 실제 맥의 launchd·KBS 도메인·사내망·SAP·MCP 운영은 여기서 검증하지 않았습니다. 자세한 결과는 `docs/VALIDATION.md`에 있습니다.
