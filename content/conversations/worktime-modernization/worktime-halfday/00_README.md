# 반일 휴가의 시간외 입력 안내 · 사례 안내

## 10. 반일 휴가의 시간외 입력 안내

### 업무 상황

오전 반일을 사용한 직원이 실제 출근시각부터 입력하면 기대한 실비와 다른 금액이 나올 수 있습니다. 오사원은 이런 결과를 계산식 오류로 단정하기 전에 정상 근무시간·휴가·휴게시간과 입력 방식부터 확인했습니다.

### 판단과 안내 기준

해당 입력 방식은 정상 근무 시작부터 전체 시간을 입력하고 승인된 반일을 별도로 반영합니다. 따라서 직원에게 “실제 출근시각”과 “시간외 입력의 시작시각”을 구분해 안내해야 합니다.



### 기술적 구현

최종안은 기존 `CHECK_ABSENCE_DATA` 처리에서 반일 상황을 찾아 기존 정보 안내 전달 경로에 `I95`와 `TEXT-E95`를 추가하는 방식입니다. 처음 검토한 여러 위치의 중복 검사와 새 조회를 줄이고, 기존 확인 결과에 필요한 안내를 연결했습니다.

또한 통상근무와 시차근무를 같은 기준으로 처리하지 않도록 범위를 구분했습니다. 안내 문구는 직원이 다음에 무엇을 입력해야 하는지 구체적으로 알려주는 방향으로 다듬었습니다. **업무 기준을 이해한 뒤 입력 안내와 코드 위치를 정한 사례**입니다.
