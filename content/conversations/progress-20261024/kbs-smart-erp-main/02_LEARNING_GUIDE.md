# 학습 순서

## 화면 개편을 기능 보존·반영 ZIP·비교 보고서의 계약으로 정리하다

디자인 목표와 레거시 ERP에서 지켜야 할 연결을 함께 정의합니다.

**교육용 재작성 프롬프트 / 실습**

“이 화면의 실제 호출 관계를 먼저 읽고 보존할 기능과 디자인만 바꿀 요소를 나누어 주세요. 전달 ZIP과 비교 보고서는 같은 최종 파일을 가리키게 만들고, 로컬 검증과 SAP 검증을 구분해 주세요.”

상위 화면 CSS만 바꾸면 메뉴 iframe의 글꼴까지 바뀐다고 가정할 수 없는 이유를 찾아보세요.

## 보이지 않는 시안을 다시 전달하고 원하는 인물 스타일을 좁히다

생성했다는 보고와 사용자가 확인할 수 있는 결과물을 구분합니다.

**교육용 재작성 프롬프트 / 실습**

“확인 가능한 파일로 시안을 제공해 주세요. 인물 표현·배치·색상·메뉴 밀도 중 무엇을 바꿨는지 나누어 설명하고, 이미지가 열리지 않는다면 실제 확인 가능한 대체 형식으로 전달해 주세요.”

## 새 레퍼런스를 따라 반투명 패널과 서버 인프라 시안을 확정하다

이전 요구와 후속 선택의 효력을 시간순으로 읽습니다.

**교육용 재작성 프롬프트 / 실습**

“초기 시안에서 유지할 것, 새 레퍼런스로 대체된 것, 나중에 별도 수정할 것을 구분해 주세요. 최종 시안의 패널 배치와 배경을 먼저 맞추고, 예시 숫자나 원본 폰트 정보를 실제 운영 근거로 취급하지 말아 주세요.”

## LED 표현을 검토하며 배경과 실제 조작부의 경계를 정하다

움직이는 배경과 클릭 가능한 업무 화면을 별도 층으로 이해합니다.

**교육용 재작성 프롬프트 / 실습**

“배경 자산, 장식 LED, 실제 텍스트·메뉴를 분리해 설명해 주세요. 창 크기와 cover 크롭이 달라져도 배경과 LED가 같은 좌표를 쓰는지 확인하고, 단순 장식을 실제 서버 상태처럼 표시하지 말아 주세요.”

## 누락 앱을 실제 참조로 찾고 확정 시안을 BSP에 구현하다

미확보 소스와 서버에 없는 기능을 혼동하지 않습니다.

**교육용 재작성 프롬프트 / 실습**

“어느 파일의 어떤 URL·함수 참조 때문에 추가 소스가 필요한지 적어 주세요. 미확보 자료는 표시하되 진행 가능한 화면은 구현하고, 예시 데이터·기존 연계 코드·실서버 시험 결과를 나누어 보고해 주세요.”

## 중앙 패널을 제거하고 결재 진입을 좌측 상단으로 모으다

후속 사용자 결정에 맞춰 이전 명세를 갱신합니다.

**교육용 재작성 프롬프트 / 실습**

“중앙 패널 제거 결정을 이전 요구보다 우선 반영해 주세요. 이동한 결재 링크의 기존 URL과 인자를 보존하고, 현재 이미지 크기와 화면의 가변 배치를 별도로 확인해 주세요.”

## 4K 재생성과 확대를 구분하고 편집 범위를 다시 한정하다

요청한 해상도·실제 출력·승인된 변환 방식을 구분합니다.

**교육용 재작성 프롬프트 / 실습**

“현재 이미지의 실제 픽셀 크기와 생성·수정·확대 중 수행한 작업을 명확히 적어 주세요. 지정 이미지의 서버·DB·케이블 수·위치·색은 유지하고 허용된 접합부만 고쳐 주세요. 변경 범위 밖을 새로 그리지 말아 주세요.”

## 4K 배경 적용 뒤 고정 프리뷰의 회색 여백을 제거하다

큰 이미지와 브라우저 창을 채우는 레이아웃을 구분합니다.

**교육용 재작성 프롬프트 / 실습**

“배경 파일의 픽셀 크기, 프리뷰 캔버스 크기, 실제 브라우저 표시 영역을 따로 확인해 주세요. 배경과 LED는 같은 cover 영역에 두고 패널은 창 크기에 대응하게 해 주세요. 실제로 시험한 조건만 기록해 주세요.”

## 창 대응을 확인한 뒤 검은 랙·부분 소등·간격을 다듬다

승인된 배치와 새 시각 수정의 범위를 분리합니다.

**교육용 재작성 프롬프트 / 실습**

“이번 수정은 랙 색·부분 소등·간격 중 요청한 항목에 한정해 주세요. 유지한 배치와 바뀐 위치를 설명하고, 소스에 아직 넣지 않은 이미지와 실제 프리뷰에 적용한 버전을 구분해 주세요.”

## 제공한 랙 이미지로 교체하고 표시한 다섯 결함만 고치다

국소 수정 요구를 결과 이미지와 적용 버전으로 추적합니다.

**교육용 재작성 프롬프트 / 실습**

“빨간 표시 영역별 결함과 수정 내용을 짝지어 설명해 주세요. 허용 영역 밖을 유지했는지 확인한 방법을 적고, 이미지 파일·소스·프리뷰가 같은 버전을 쓰는지 대조해 주세요.”

## S-Core Dream을 iframe별로 적용한 v9를 전달하다

글꼴 파일 확보·실제 로딩·사용자 수용·SAP 반영을 구분합니다.

**교육용 재작성 프롬프트 / 실습**

“실제 사용한 폰트 파일·굵기·출처와 적용한 문서를 정리해 주세요. 각 iframe에서 로딩된 글꼴을 확인하고, 다른 업무 화면에 선택자가 퍼지지 않는지 점검해 주세요. 파일 생성과 서버 적용 상태는 따로 적어 주세요.”

## 맥락 문서에서 불완전한 ZIP을 드러내고 개편의 가치를 성찰하다

구현물 존재와 완전한 전달, 요청자 만족과 조직적 가치를 구분합니다.

**교육용 재작성 프롬프트 / 실습**

“구현 코드·보관된 로컬 시험·사용자 확인·실제 서버 반영·전달 ZIP 무결성을 각각 기록해 주세요. 파일을 다시 열어 본문을 확인하고 원문과 새 묶음을 구분해 주세요. insight에서는 요청자의 미감과 일반 이용자의 경험이 같다고 가정하지 말아 주세요.”
