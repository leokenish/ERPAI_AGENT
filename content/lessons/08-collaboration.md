# 담당 에이전트에게 원격 자문하기

## 사람의 업무 분장을 따라가는 구성

담당자별 맥에 자기 소스와 지식을 두고, 중앙 MCP로 질문과 근거 답변을 주고받는 설계입니다.

외부 질문은 별도 자문 워커가 처리합니다. Desktop 대화 이력 공유는 별도 구현 대상입니다.

## 실제 예제가 제공하는 범위

`erp-team-mcp-example 0.1.0`은 Node.js 중앙 서버·SQLite·MCP 도구·모의 FI 워커를 제공합니다. 실제 AI 자문 연결은 미구현입니다.

| 구성 | 역할 | 상태 |
|---|---|---|
| ask_expert | 질문을 등록하고 job_id 반환 | 예제 구현 |
| get_answer | 본인 작업의 상태·답변 조회 | 예제 구현 |
| list_experts | 허용 담당과 최근 통신 확인 | 예제 구현 |
| 워커 claim·complete | 작업 배정과 결과 제출 | 모의 시험 기록 |
| FI 자문 AI | FI 소스·지식을 읽어 답변 | 미구현 |

후속 질문은 별도 follow_up 도구 대신 ask_expert의 parent_id를 사용합니다.

## 한 질문이 처리되는 순서

1. HR 에이전트가 FI 담당과 질문·맥락을 지정합니다.
2. 중앙 서버가 인증과 허용 담당을 확인하고 queued 작업을 만듭니다.
3. FI 워커가 작업을 가져가면 running 상태와 lease가 생깁니다.
4. 현재 모의 워커는 실제 분석 없이 `[MOCK]` 응답을 만듭니다.
5. 유효한 lease로 결과를 제출하고 HR이 get_answer로 조회합니다.

`done`은 결과 등록 완료를 뜻합니다. 답변의 업무 정확성은 담당자가 검토합니다.

## 따라 하기: 모의 통신 검증

[중앙 MCP 예제 ZIP](downloads/ERP_MCP_NodeJS_Example.zip)을 별도 폴더에 풀고 그 안의 README부터 읽습니다. 예제는 Node.js 24 이상과 패키지 설치가 필요합니다. 교육 포털 서버와 다른 프로젝트입니다.

```bash
cd <예제를_푼_폴더>
npm ci
npm test
```

원천 기록의 통신 테스트 1개가 요청·배정·답변·접근 차단·후속 이력·lease 거절을 확인했습니다. 실제 AI·사내망·장기 운영 검증은 추가 과제입니다.

## 실제 운영으로 넘어갈 때

- 읽기 전용 자문 작업 사본과 실행 권한을 정합니다.
- 실제 AI 실행, heartbeat, 취소와 시간 제한을 구현합니다.
- 중복 요청과 실패 후 재시도 정책을 정합니다.
- 상대 답변에 근거 파일·커밋·미확인 사항을 포함합니다.
- 기본 루프백 HTTP를 사내 운영용 주소·인증 방식으로 구성합니다.

자문 예제는 작업 저장에 SQLite를 사용합니다. 교육 포털은 정적 파일로 운영하며, ERP 조회 MCP의 구성은 별도로 결정합니다.
