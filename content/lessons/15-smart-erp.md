# 스마트 ERP 메인화면 개편

## 업무 연결과 첫 화면 개편

메인화면의 메뉴·결재·공지·서식은 직원이 매일 사용하는 업무 경로입니다. 따라서 기존 연결을 유지하면서 배치·배경·글꼴을 개선하는 방향으로 진행했습니다. 아래 내용은 시안 선택부터 페이지 구성과 로컬 프리뷰까지 이어지는 적용 과정을 설명합니다.

## 디자인과 배치 기준

| 항목 | 적용 방향 |
|---|---|
| 배경 이미지 | 서버 인프라 시안과 반투명 패널 |
| 주요 영역 | 중앙 패널 정리와 결재 링크 이동 |
| 큰 창 대응 | 전체 창에 맞춘 페이지·패널 배치 |
| 랙·케이블 | 기준 이미지의 주변 배치를 유지한 부분 보정 |
| 글꼴 | 관련 화면과 iframe의 S-Core Dream 적용 |

기준 시안을 정한 뒤에는 화면 전체를 다시 그리기보다 수정할 부위를 좁혔습니다. 그래야 선택한 배치와 분위기를 유지하면서 케이블·간격·여백을 조정할 수 있기 때문입니다.

## v9 소스와 로컬 프리뷰

v9의 네 MD에는 원본 2,486개 경로 중 누적 7개를 변경한 내용과 로컬 화면·글꼴 시험 기록이 정리되어 있습니다. 메인페이지와 연결된 내부 페이지를 함께 살펴보고, 배경 이미지와 실제 클릭 영역의 배치를 비교했습니다.

![v9 1900×932 로컬 프리뷰](assets/images/smart-erp-v9-preview.jpg)

## 화면 구성 검토

1. 기준 시안과 프리뷰의 메뉴·결재·공지 영역을 비교합니다.
2. 창 크기를 바꾸며 배경·패널·내부 페이지의 배치를 살펴봅니다.
3. 버튼과 메뉴의 호출 주소·전달값을 기존 소스와 대조합니다.
4. 글꼴·행 높이·선택 표시가 각 영역에서 일관되게 적용되는지 살펴봅니다.
5. 변경한 파일과 연결된 앱을 목록으로 정리합니다.

## 프로젝트 문서와 가치 성찰

[자료실](#/library/smart-erp)에서 intent·spec·plan·insight와 프리뷰·변경 보고서를 내려받을 수 있습니다. 목적·요구사항·진행 계획을 읽은 뒤 화면을 비교하면 각 디자인 선택이 어떤 요구에서 출발했는지 이해하기 쉽습니다.

insight는 매일 사용하는 업무 환경을 세심하게 가꾸는 가치와 별도 개편을 추진하는 이유를 살펴봅니다. 또한 만드는 사람의 만족과 실제 이용자의 경험을 함께 돌아보도록 구성했습니다.
