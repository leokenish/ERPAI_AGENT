## 1. 이유

스마트 ERP의 메인화면은 매일 메뉴·결재·공지·서식으로 들어가는 출발점입니다. 기존 기능을 계속 이용하면서도 많은 버튼·아이콘·배경을 더 읽기 쉽게 정돈할 필요가 있었습니다.

따라서 이 사례는 **익숙한 업무 경로를 유지하면서, 선택한 디자인을 실제 ERP 화면 구조에 맞게 구현하는 것**을 목표로 삼았습니다. AI 시안을 출발점으로 삼되 기존 페이지와 연결된 메뉴·결재·게시판을 함께 살펴보는 방식으로 진행했습니다.

## 2. 실제 근거·시행착오

초기 인물 중심 시안은 원하는 분위기와 달라 반투명 패널과 서버 인프라 배경으로 방향을 바꿨습니다. 하지만 배경을 4K로 준비해도 페이지가 고정 크기이면 큰 창에 회색 여백이 남았습니다. 따라서 이미지의 해상도와 별도로 페이지·패널이 창 크기에 맞춰 배치되도록 조정했습니다.

케이블 접합이나 서버 간격을 보정할 때는 이미 선택한 주변 배치까지 달라지는 문제가 있었습니다. 이에 기준 이미지를 다시 지정하고 수정할 부위만 좁혔습니다. **시안의 분위기, 창 크기에 맞는 배치, 이미지의 부분 보정**을 각각 나누어 다룬 이유입니다.

## 3. 방향 설정

선택한 디자인을 구현하는 동안 기존 기능이 달라지지 않도록 메뉴 계층·권한·주소·버튼 동작을 보존합니다. 그 위에서 글꼴·행 높이·선택 표시를 개선합니다. 중앙 패널 제거와 결재 링크 이동처럼 후속으로 정한 배치도 같은 기준에 반영합니다.

또한 배경 그림과 클릭할 수 있는 HTML 영역을 나눕니다. 화면 전체를 한 장의 그림으로 만들면 실제 메뉴·텍스트·게시판을 사용할 수 없기 때문입니다. 따라서 배경은 분위기를 만들고, 업무 요소는 기존 페이지 연결을 유지하는 역할로 구성합니다.

## 4. 기술적 구현

메인화면에는 여러 페이지가 연결되어 있으므로, 대표 화면의 CSS와 함께 내부 페이지의 참조도 살펴봅니다. BSP는 SAP의 웹페이지 구성 방식이며, iframe은 한 화면 안에 별도 페이지를 담는 영역입니다.

1. **연결된 앱 조사:** `ZWEB_COMMON`, `ZWEB_MENU`, `ZWEB_WF`, `ZBULLETIN_BOARD`에서 메뉴·결재·게시판이 호출하는 페이지를 찾습니다.
2. **표현 역할 분리:** 배경은 이미지로 두고 메뉴·결재·게시판은 HTML로 유지합니다. 기존 호출 주소와 전달값도 보존합니다.
3. **창 크기와 글꼴 조정:** 페이지·패널의 크기와 배치를 조정하고, v9의 관련 화면과 iframe에 S-Core Dream을 적용했습니다.
4. **로컬 프리뷰 비교:** 모의 응답을 사용하는 프리뷰에서 전체 배치·글자·연결 영역을 살펴봅니다.
