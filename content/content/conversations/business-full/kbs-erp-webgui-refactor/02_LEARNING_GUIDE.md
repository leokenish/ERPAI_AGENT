# 학습 안내

에피소드의 대화 전문을 읽고 교육 해설·결과·실습 탭으로 이동합니다. 첨부 전용 요청은 파일명과 확보 상태로 표시됩니다.

- CSS 디자인 목표와 전체 소스 분석 요청: 초기 CSS 16개 파일의 수정본을 확보했습니다. 이후 전체 WEBGUI 분석·실행 검증과는 시점과 범위가 다릅니다.
- 빈 파일을 다시 확보하고 보존 기준을 세우기: 초기 구현·680건은 당시 발화 및 확보한 보고서·Evidence 기록으로 확인한다. 이번에는 파일을 대조했으며 모의 기능 검증을 재실행하지 않았다. 사용자의 일부 확인을 v3 검증으로 확대하지 않는다.
- 사용자 실행 피드백으로 스크롤 문제를 분리하기: 4개 국소 패치·916건은 당시 보고서와 Evidence 기록으로 확인한다. 사용자의 초기 기능 확인은 제한적이며 실제 체감 개선·중복 POST는 미확인이다.
- 캐시 요청과 요청 전 타이머를 구분하기: 당시 캡처 판독과 해석을 보존. Network 이미지 원본은 최종 로컬 대조에서 확인했다. 정확한 호출 경로와 업무 HTML은 미확인이다.
- 잘못 선택한 메뉴 문서를 고쳐 실제 업무 POST를 확인하기: 업무 POST와 HTML 응답은 당시 판독문 및 이번에 직접 열람한 이미지로 확인했다. 실제 요청 중복과 스크롤 핸들러 연결은 미확인이다. 원본 이미지는 식별자 때문에 대부분 배포 제외한다.
- 화살표 오류로 제공 소스와 배포 응답을 대조하기: SYSTEMGUI 최적화·원본·증빙, 커서 수정·롤백 파일을 대화에 연결했습니다. 실제 운영 원인은 미확정입니다.
- Chrome 우선순위와 새 HTML을 반영해 v3를 검토하기: 100개 전체 파일 중 HTML 14개·JS 16개·CSS 3개 수정 및 모의 회귀 186건은 당시 보고입니다. 실제 Chrome·ERP 화면 검증은 미완료입니다.
- 구조 개선 제안을 구현과 구분해 후속 과제로 남기기: 구조 개선 제안 전문 확보. 후속 구조 변경을 이번 작업에서 실행하지 않았습니다.
- 요약 자료를 대화·근거·실습이 연결된 교육 데이터로 바꾸기: 이번 교육 추출의 완성은 패키지 검증으로 확인한다. 포털 배포·운영 승인·v3 ERP 성공을 의미하지 않는다.
- Modern V1: 보존 조건과 디자인 범위: 기존 화면 캡처와 ITS 소스를 바탕으로 V1 결과가 제시됐습니다. 디자인 비교 화면은 실제 SAP 실행 결과로 확대하지 않습니다.
- CSS 21개와 SE80 반영 단위: 21개 CSS 수동 반영 범위를 설명한 뒤 JS와 템플릿까지 분석 범위가 넓어졌습니다.
- Modern V2: 112개 객체와 검증 범위: 원 대화의 AI는 정적 20개·로컬 Chromium 25개 검사를 보고했습니다. 이 포털에서 SAP 또는 Windows Chrome·Edge 운영 동작을 재검증한 결과는 아닙니다.
- ITS 비교·저장·활성화 도구 검토: ALV 비교와 선택 반영은 설계 검토입니다. SAP 700 API·권한·잠금·CTS·백업·발행 순서 검증 및 실제 적용은 남아 있습니다.
