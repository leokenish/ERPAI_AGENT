# ERP MCP 서버 구성 — 자료 안내

- 프로젝트명: ERP MCP 서버 구성
- 대화 주제: 기존 ECC REST/RFC 연동의 MCP 도구화와 Telegram 기반 원격 에이전트
- 정리 기준일: 2026-10-08, Asia/Seoul
- 문서 성격: 현재 대화의 근거를 보존한 교육 포털 통합용 추출본
- 추출본 버전: 1.0
- 구현 상태: 설계 논의·설명용 코드 제시. 실제 서버 설치·ERP 연동·Telegram 왕복·운영 성공은 이 대화에서 확인되지 않음.

## 1. 프로젝트 목적과 현재 상태

기존 ECC 6.0에서 사용 중인 JSON REST API와 RFC 업무 함수를 활용하여, AI 에이전트가 자연어 질문에 필요한 ERP 데이터를 조회하도록 연결하려는 프로젝트다. 패키지 추출로 확보한 ABAP 소스·구조를 분석하는 에이전트에 실제 데이터 조회 수단을 더하는 것이 첫 목적이다. 이후 회사 밖의 모바일 Telegram에서 질문하고 사내 에이전트의 답변을 받는 요구로 확대되었다.

사용자는 MCP와 에이전트를 사내망에 둘 계획, VPN·원격 화면보다 채팅형 사용을 원하는 점, 서버 한 대라는 제약을 직접 밝혔다. 이에 대해 별도 ERP MCP 프로그램, Telegram long polling 연결 프로그램, Codex 기반 에이전트를 한 장비에 배치하는 구성이 제안되었다. 설치 언어·장비 구매·첫 ERP API·운영 계정은 확정되지 않았다.

이 자료의 ‘현재’는 **확인된 대화에서 가장 뒤에 제시된 방향**을 뜻한다. 사용자 서버의 2026-10-08 현재 실태를 원격 점검했다는 뜻이 아니다.

## 3. 확인하지 못한 자료

- 회사 서버·Mac의 실제 설치 상태, OS 버전, 실행 프로세스, 서비스 등록 파일, 로그.
- 실제 ERP REST URL·인증 방식·요청/응답 명세·RFC 함수 소스·사용자 권한 매핑.
- 패키지 추출 ZIP, 업무별 에이전트 지침·스킬·하네스 원문, GitHub 저장소 최신 커밋.
- Telegram 봇 토큰 설정·사용자 허용 목록·대화 상태 저장·실제 송수신 결과.
- 기존 MD 또는 첨부파일 중 현재 MCP 프로젝트의 최신본으로 확인할 수 있는 원본.
- 별도 ‘ERP AI 에이전트간의 통신’ 프로젝트 ZIP 내부와 Node.js 구현 상태.
- M6 Mac mini 구매 여부. 과거 답변의 가격·출시·세부 사양은 이번에 재검증하지 않았다.

다른 프로젝트의 기억·검색 스니펫을 이 프로젝트의 구현 결과로 옮겨 적지 않았다. 이 추출본에는 현 대화에서 직접 다루지 않은 Obsidian 상세 설정, Export/Import 구현, GitHub Actions 실행, 업무별 서브에이전트 구현을 포함하지 않는다.
