## 최신성 적용 규칙

위 URL은 업데이트될 수 있다. 설치 시에는 실제 패키지 버전과 코드 API를 함께 확인하고 잠금 파일 또는 버전 기록을 남긴다. 이번 추출은 서버 설치 요청이 아니므로 SDK를 설치하거나 네트워크 봇·AI 모델·ERP를 실행하지 않았다. 문서가 예제를 지원한다는 사실만으로 사용자의 환경에서 동작했다고 표기하지 않는다.

MCP 프로토콜 버전, Python SDK 버전, Codex 버전은 서로 다른 값이다. `mcp[cli]>=2,<3` 같은 명령은 SDK의 메이저 범위이며 재현 가능한 정확한 배포 버전 고정을 대신하지 않는다.
