## 검증되지 않은 내용

- 플랫폼 전체 원 대화와 기존 A001–A006의 재대조. 기존 verbatim 표시를 승계했으며 새로 검증 완료했다고 표시하지 않는다.
- U002–U090의 AI 설명·코드 안내 전문과 일괄 응답 관계.
- 검색 요약에 등장한 일시 후보·원문 위치. timestamp에 사용하지 않았다.
- DIAG 0.4.5의 실제 SAP 실행·활성화, 대응 Export ZIP, 현재 Mac/GitHub/업무 하네스 상태.
- 기존 소스의 기능·업무 답변 정확성을 이번 작업에서 재검증한 것은 아니다.

이 검증 통과는 **교육 파일의 내부 정합성**을 뜻한다. 전체 대화 복구 성공 또는 SAP 동작 보장을 뜻하지 않는다.
