# 자료 안내 — ERP AI 에이전트간의 통신

- 프로젝트명: ERP AI 에이전트간의 통신
- 대화 주제: 담당자별 맥·패키지 에이전트와 중앙 MCP를 통한 원격 자문 협업
- 정리 기준일: 2026-10-08, Asia/Seoul
- 자료 묶음 버전: 교육 추출본 1.0.0
- 기존 코드 버전: erp-team-mcp-example 0.1.0 (교육 추출본 버전과 별개)
- 용도: 여러 프로젝트 자료를 통합할 교육 포털의 콘텐츠 원본. 포털·서버를 새로 구축하거나 GitHub에 push한 결과가 아니다.

## 1. 목적과 현재 상태

KBS ERP 담당자가 자기 패키지 소스·업무 지식만 관리하면서, 다른 업무의 전문 에이전트에 질문하고 답변을 받아 협업하는 구조를 설계했다. 대표 요구는 HR 담당자가 ZHR에서 시간외 정산을 다루다가 FI 전표에 관해 물으면 ZFI가 자문에 참여하는 것이다.

최종 사용자 요구는 **담당자마다 맥을 제공하고 자기 ZXX만 클론하며, 중앙 MCP를 통해 다른 맥의 담당 에이전트에게 질문**하는 방식이다. 모두 ERP 최상위 폴더를 열어 모든 패키지를 수정하는 방식도, 사람이 검토 요청서를 수동 전달하는 방식도 최종 요구가 아니다.

현재 확보된 것은 Node.js 중앙 MCP 예제와 모의 워커이다. 자문 요청/조회/담당 배정/후속 문맥/일부 접근 제한은 구현되어 있으며 자동 통합 테스트가 있다. **실제 FI Codex 자문 실행, 담당자 맥 간 연결, 사내 HTTPS, 실제 ERP 코드 분석, 운영 배포는 확인되지 않았다.**

| 구분 | 확인 상태 |
|---|---|
| 사용자 목표·구성 방향 | 대화에서 명시적으로 확인 |
| 중앙 MCP 예제 | 코드 0.1.0 확보·내용 확인 |
| 모의 통신과 권한 분리 | 원 대화의 시험 통과 기록 있음; 이번 재검증 결과는 참고자료 확인 |
| 실제 AI 자문 워커 | 구현 파일 없음, 연결 지침만 있음 |
| 원격 수정 금지 | 요구·설계 원칙; 실제 AI 실행 권한 격리 검증은 미실시 |
| KBS 운영 도입 | 미확인 |

## 2. 실제 확인 범위

1. 현재 대화에 표시된 2026-10-03 01:18~01:58 KST 사용자 발언, 그 응답과 코드 제작 도구 기록, 2026-10-08 자료 추출 요청.
2. 저장된 `ERP_MCP_NodeJS_Example.zip`을 이번에 다시 확보하여 내부 6개 파일을 확인. 본문 코드·README를 읽고 package-lock.json을 파싱하여 의존성 버전을 확인했다.
3. 원 대화에서 공식 문서를 조회한 내용은 역사적 참고로만 사용. 이번 추출에서 공식 문서의 최신 내용이나 사용자의 설치 앱 버전을 재확인하지 않았다.
4. 프로젝트 범위의 추가 MCP 자료 검색에서는 추가 결과를 확보하지 못했다. 검색 결과 없음은 해당 자료가 존재하지 않는다는 증명이 아니다.

원 ZIP은 2026-10-03 02:05 KST에 해당하는 저장 메타데이터로 확인된다. 코드 버전은 package.json의 0.1.0이다. 이번에 접근 가능한 일치 ZIP은 이 한 건이며, 다른 맥·GitHub에 더 최신본이 있는지는 알 수 없다.

## 3. 확인하지 못한 범위

- 다른 대화방 전체, 프로젝트 내 모든 비공개·미첨부 자료.
- 실제 ZHR/ZHR5/ZFI/ZMM 저장소, ABAP 코드, 업무 매뉴얼·회의록 원문.
- 사용자가 보유한 실제 AGENTS.md, SKILL.md, knowledge/ 및 harness/의 최신 내용.
- 각 담당자의 Codex Desktop 버전·설정·계정·MCP 연결 화면.
- 중앙 서버 장비·OS·실제 주소·인증 구성·서비스 운영 기록.
- 실제 맥 화면 캡처와 사용자 측 실행 로그.

이 자료의 시간외 전표 사례는 협업 설계용 사례이지 KBS의 실제 전표 취소 로직을 확인한 결과가 아니다. SAP ECC/BASIS 상세 버전, 원격 API, CTS 구현 등은 본 대화 원자료로 확인하지 않아 이 프로젝트의 검증 환경으로 확정하지 않는다.

## 5. 상태와 출처 표기 규칙

- 제안: assistant가 제시한 방법. 사용자 무응답을 채택으로 해석하지 않는다.
- 결정: 사용자가 명시한 운영 방향·제약. 제품 구현 완료라는 뜻이 아니다.
- 구현: 확보된 파일의 코드로 확인한 내용.
- 검증: 실제 시험 기록이 있는 범위에 한정한다.
- 운영: 사용자 환경에서 실제 가동한 증거가 있을 때만 사용한다. 현재 운영 확인 없음.
- 미확인: 원문·실행 결과·설정이 없어 판단 불가.

각 문서의 `[C01]` 등은 [출처와검증기록](references/출처와검증기록.md)의 현재 대화 발언 시점이다. `[F-SERVER]` 등은 ZIP 내부 파일이다. 출처 절 번호는 교육 문서의 절 번호이며 존재하지 않는 원문 페이지를 만들지 않았다.
