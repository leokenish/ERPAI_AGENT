# 시간외 기준단가 — 2026-09-01 변경

## 현재 답변에 적용할 기준

2026-09-23 사용자는 “최근에 2026년 9월 1일부터 시간외 단가가 8400원 -> 9240원으로 변경됐어. 수정이 필요해”라고 정정했다. 해당 인상 대상의 시간외 기준단가는 **2026-09-01부터 8,400원 → 9,240원**으로 설명한다. [SRC-12, 2026-09-23 사용자 설명]

현재 기준을 묻거나 시행일 이후 계산 예시를 들 때는 인상 대상임을 전제로 9,240원을 사용한다. 8,400원은 시행 전 사례 또는 인상 제외 대상임을 명시할 때만 사용한다. 과거 협의·매뉴얼의 수치를 일괄 치환하지 않는다.

확인 상태: 변경 금액과 시행일은 사용자 설명으로 확인했다. 공식 승인문서 열람, SAP 배포·실제 지급 검증을 수행했다는 뜻은 아니다. 이 정리본 전체의 담당자 검토는 대기 상태다.

## 직군별 현행 기준 — SRC-13 후속 정정

2026-09-23 사용자 정책 설명에 따라 연봉계약직·특정업무직은 2026-09-01부터 모두 시간외 A등급을 적용하고, 방송지원직은 계속 D등급을 적용한다. [SRC-13]

| 직군 | 적용 등급 | 시간외 기준단가 |
|---|---|---:|
| 정규직 | 이번 설명으로 등급 코드는 별도 확정하지 않음 | 9,240원 |
| 연봉계약직 | 모두 A | 9,240원 |
| 특정업무직 | 모두 A | 9,240원 |
| 방송지원직 | D 유지 | 5,400원 |

앞선 답변의 “연봉계약직·특정업무직은 개인별 등급에 따라 현행 단가 미확인”과 “방송지원직 D 외 8,400원”은 현행 정책 설명으로 대체한다. 기존 협의 기록은 당시 설명으로 보존한다. 방송지원직의 “계속 D”를 과거 모든 기간의 개별 마스터가 D였다는 검증 결과로 확대하지 않는다.

개별 마스터가 다른 등급으로 보이면 현행 정책과 등록 상태의 불일치를 확인할 사안이지, 그 값을 곧바로 정책상 예외로 설명하지 않는다. 정책 변경 확인과 전 직원 마스터 변경·과거 입력 보정·SAP 지급 검증은 별개다. 이 문서 전체의 검토 상태는 유지한다.

## 선택근무의 기간 경계

기존 협의 정리본의 발생일별 적용 설명은 유지한다. 2026-09-01 이후 직군 기준에는 위 SRC-13 정정을 우선 적용한다.

- 휴일·야간·대휴실비: 근무일 기준 단가.
- 연장실비: 소정을 넘는 연장시간 발생일 기준 단가. 4주 종료월의 단가를 전체 기간에 일괄 적용하지 않는다.
- 2026-08-31에 8,400원 적용 대상이었던 직원의 2026-08-31 연장 1시간과 2026-09-01 연장 9시간은 1×8,400 + 9×9,240 = **91,560원**이다.
- 방송지원직은 D등급 5,400원을 유지한다. 기존 “그 외 등급 8,400원” 설명은 과거 협의 이력이며 현행 안내로 사용하지 않는다. [SRC-13]

근거: [SRC-10 L2968–3005, 2026-07-29]. 이 구간은 과거 합의 기록이며 이번에 원문을 재열람한 것은 아니다. [협의 정리본](../feedback/SRC-10-late.md)

등급 변경 후 현재 입력이 9,240원으로 보이는 사실과 과거 입력의 보정 완료는 별개다. 사용자 단가 정정만으로 과거분 보정 완료를 선언하지 않는다. [SRC-11 L328–366, 2026-09-16~18; 협의 정리본](../feedback/SRC-10-early-SRC-11.md)

## 앞선 선택근무 예시의 단가 정정

조건: 인상 대상, 관련 근무일·연장 발생일 모두 2026-09-01 이후, 소정 160시간, 평일 170시간, 휴일 3일 각 8시간, 대휴 3일/24시간, 지급 대상 연장 10시간, 야간·시차 없음. 시간 산정 조건은 앞선 예시 그대로 두고 단가만 정정한다. 실제 SAP 계산 결과가 아닌 설명용 산술이다.

| 항목 | 정정 계산 | 금액 |
|---|---|---:|
| 연장실비 | 10×9,240 | 92,400원 |
| 휴일실비 | 24×9,240×0.5 | 110,880원 |
| 합계 | 92,400+110,880 | **203,280원** |

별도 대휴 3일은 동일하다. 종전 예시 184,800원 대비 18,480원 증가한다. 단가 변경이 근무시간·대휴 발생조건을 변경했다는 근거는 없다.

근거: 시간 구성 [SRC-02 pp.5–6], 연장실비 검증식 [SRC-11 L139–143, 2026-08-28], 단가·시행일 [SRC-12]. 원래 답변과 수정 이력은 [FB-20260923-001](../../harness/feedback/FB-20260923-001.md)에 기록한다.
