# 근로시간 업무 흐름과 상태 경계

상태: 여러 원문을 연결한 분석 초안. 규정의 승인이나 실제 프로그램 호출 순서 검증을 대신하지 않는다.

## 근무유형별 입력과 정산
| 유형 | 입력/기준 | 정산 시 확인 | 근거 |
|---|---|---|---|
| 통상·시차 | 사용자 PC/모바일 근무·휴게·결재, 익휴/퇴출 등의 조건 | 일별 실비, 주간 제한, 승인 전후 금액, 계좌/마감 | SRC-03 p.1; SRC-05 L15; SRC-10 L316–383 |
| 교대 | 등록 대상·사전 스케줄과 추가 실적 | 표시된 실적만이 아닌 스케줄 기준시간, 직급·보상휴가 | SRC-05 L16; SRC-10 L2152–2169 |
| 선택 | 4주 대상기간, 일별 실적·휴게·근태/출장 | 소정 충당, 휴일/간주/가산시간, 누락분, 대휴 생성 | SRC-02 pp.4–11; SRC-07/09 협의 |
| 재량 | 대상기간·수당 구분 등록 | 사후 등록분·정산월·확정 상태·PA2010 합산 | SRC-05 L18; SRC-11 L81–101, L174–195 |
| 간주 | 해당 출장의 간주 등록 여부 | 근무일/기간·대휴 생성일·실제 정산일 구별 | SRC-05 L19; SRC-10 L1753–1767, L1940–1990 |

## 상태를 분리해야 하는 이유
입력 화면 계산, 저장 데이터, 결재 상신/승인 후 재계산, 월마감, 생성된 대휴, 지급 항목, 전표, 은행 전송은 별도 상태다.
4/1 시차실비 제외는 저장에는 성공했지만 상신 뒤 금액이 되돌아갔다. 7/9 EDI 날짜 내부 수정의 중간 성공 보고 뒤 은행 반영 실패가 발견됐다. [SRC-10 L316–383, L2431–2567, 2026년]
따라서 한 화면이 맞거나 “수정했다”는 말이 있다고 전체 지급이 정상이라고 결론내리지 않는다.

## 월 정산과 누락분
담당자 인수인계는 월10일 무렵 실비 산정/전표 흐름을 설명한다. 2026-08-31 대화는 매월5일 입력마감, 6일부터 정산하며 해당9월은7일 재직자·8일 퇴직자 작업이라고 구체화한다. 매월 동일한 영업일이라고 일반화하지 않는다. [SRC-05 L15–19; SRC-10 L3440–3443]
당시 통상→선택, 선택 완료 뒤 재량·간주 작업이 가능하다는 담당자 설명이 있다. 이는 확인할 운영 의존성이지 소스에서 검증한 불변 호출 순서가 아니다. [SRC-10 L410–421; SRC-11 L253–269]

누락분(기존 지급/입력 없음), 환수환급(기지급 수정), 퇴직자 별도 정산을 구별한다. 이미 지급한 누락분을 다시 합산하거나 환수환급 재입력이 누락분으로 들어가면 중복 위험이 있다. [SRC-10 L599–626, L3365–3390; SRC-11 L155–164]
PA2010에서 지급 대상만 제외하는 요청과 선택대상/일별 실적 삭제는 다른 작업이다. 실제로 혼동으로 실적 삭제 후 복구한 이력이 있다. [SRC-07 L314–346]

## 소급 변경
달력 변경→등록 소정시간, 휴가 취소/반려→소정/달력, 실적 보충→이미 생성한 대휴, 등급 변경→기존 입력금액은 자동으로 함께 고쳐진다고 가정하지 않는다.
관련 사례: 소정 -8시간 별도 보정 [SRC-10 L2393–2415], 대휴 고정값 후속수정 [SRC-10 L1478–1505], 연차 변경 롤백 [SRC-11 L196–215], 등급 변경 후 과거분 미보정 [SRC-11 L328–364].

## 변경 검토에 필요한 최소 입력
기준일·대상월, 근무유형/대상기간, 승인 상태, 실제 근무와 휴게 구간, 근태/출장 상태, 직군·직급·등급의 유효일, 기존 정산/대휴/지급 여부, 오류 화면의 표시값과 저장값.
직원 식별자는 익명 사례 ID로 전달하고 실제 운영 대사는 담당자가 제한된 환경에서 수행한다.

## 통상·시차 입력 시각 확인

반차·지참·조퇴·자율출근이 있는 시간외 문의는 [입력 시작시각 기준](overtime-start-time.md)을 먼저 확인한다. 통상·시차는 기준 출근시각부터 입력하는 방식이며 선택근무의 실제 근무시각 입력과 구분한다. 입력시간 부족으로0원이 된 것을 곧바로 필수근무 검사 결함으로 단정하지 않는다. [SRC-14, 2026-10-01]
