# 교육 대화 통합 기록

2026-10-14 · 포털 v1.10.0

현재 수록 범위는 6개 프로젝트·59개 에피소드·407개 항목입니다. 네 프로젝트의 공유 대화를 반영한 상세 범위와 남은 누락은 문서 끝의 v1.10.0 절을 참조하세요. 아래 v1.7.1 표는 이전 통합 당시의 기록입니다.

## 화면에서 읽는 방법

1. 전체 구성도의 SAP·Export를 선택하면 최초 목적과 환경 확인 또는 첫 추출기 제작부터 읽는다.
2. GitHub·Codex·업무 지식·DIAG·피드백 등 다른 요소는 해당 학습 흐름으로 바로 연결된다.
3. 대화 기록에서 요청·응답을 순서대로 읽고, 긴 항목은 전문 펼치기로 확인한다. 다음 대화/전체 대화 펼치기로 이어 읽는다.
4. 해설·시행착오, 따라 하기, 프로젝트 맥락, 관련 자료에서 교육용 설명과 원천 근거를 구분한다.
5. 왼쪽 프로젝트 대화 메뉴에서는 구성도 필터 없이 6개 프로젝트를 탐색한다. 제목·요청·AI 본문은 전체 검색에 포함된다.

## 소스 추출 학습 흐름

초기 27개 대화쌍을 다음 네 단계로 추가했다. 이어지는 E01~E18은 기존 주소를 유지하며 실제 요청 뒤에 대응 AI 응답을 연결했다.

| 새 에피소드 | 공유 대화 번호 | 학습 내용 |
|---|---|---|
| E00-start | 1–4 | 시작 목적·SAP 환경·최초 진단 |
| E00-export | 5–14 | 첫 추출기·언어·함수 소스·내부 INCLUDE |
| E00-web | 15–23 | 다른 패키지·BSP/MIME·BASIS 700 오류·범위 |
| E00-context | 24–27 | 맥락 문서·파일명·언어 정책·인코딩 |

최초의 Import·활성화 목표는 E16에서 읽기 전용 DIAG로 바뀐다. 과거의 구현 제안을 현재 운영 기능으로 승격하지 않는다. 현재 확보한 Export 0.3.18·DIAG 0.4.5 파일과 실제 SAP 실행 성공은 별도다.

## 통합과 보존 규칙

- 새 공유 추출물: sources/conversations/20261013-shared/kbs-erp-export-diag-agents. ZIP 내부 파일을 바이트 그대로 보존했다.
- 이전 추출물: sources/conversations/20261012 및 20261012-supplement. 원문·첨부·해시를 수정하지 않았다.
- 게시용 전문과 학습 해설: content/conversations/export-full. 원래 SHARE 식별자와 플랫폼 발화 ID, 순서, 본문, 미확인 시각을 보존한다. 교육 해설과 실습은 별도 필드다.
- content/conversations/catalog.json의 sourcePath가 게시 데이터를 선택하고 assetSourcePath는 이전에 확보한 첨부 위치를 가리킨다. 첨부를 중복 복사하거나 새로운 다운로드로 꾸미지 않는다.
- content/conversations/editorial-prompts.json: 사용자 문장만 정중한 교육용 문장으로 다듬으며 원문 SHA-256으로 연결한다. AI 본문은 편집하지 않는다. 원문 확인·원문 복사 UI는 다시 추가하지 않았다.
- 게시 순서는 공유 화면을 기준으로 한다. 이전 U030/U031 중복 요청은 같은 공유 요청을 가리켜 한 번만 표시한다. 이전에 수록됐던 별도 진행 안내는 보존 원천에 남기며 공유 경로에 임의 삽입하지 않는다.
- content_type=unavailable은 빈 assistant 본문과 no_response_body_visible 상태를 함께 요구한다. 화면에는 별도의 중립 안내 상자로 렌더링한다.
- 모든 항목은 적어도 하나의 학습 에피소드에서 접근 가능하며, 요청과 대응 응답 위치는 같은 에피소드에 연결한다.

관련 자료에서 프로젝트 맥락·학습 가이드·대화 JSON·전문 MD·본문 없는 위치 목록을 받을 수 있다. 원천 HTML과 실행 코드를 통째로 웹에 게시하지 않으며, 표시용 Markdown은 기존 안전한 렌더러를 사용한다. 과거 sandbox 링크와 미확보 상대 경로는 가짜 다운로드를 만들지 않는다.

## 갱신과 검증

일반 운영은 Node.js의 npm run build, npm test, npm run preview:file로 충분하다. scripts/integrate-shared-conversation.py는 이번 자료를 편집 데이터로 구성한 재현용 도구이며 일반 빌드에 Python을 추가하지 않았다.

32개 자동 검증으로 원문 보존·전체 참조·58개 에피소드의 5개 탭·구성도 진입·복사·검색·첨부·다운로드·발표·테마를 확인했다. UI 이동 로직은 DOM 대역 검증이며 실제 브라우저의 줄바꿈·모바일·Safari 렌더링은 이 환경에서 확인하지 못했다. 자세한 범위는 VALIDATION.md에 있다.

이전 통합 상태와 당시의 “미확보” 설명은 history/CONVERSATION_INTEGRATION_v1.7.0.md에 이력으로 남겼다.

사용자 교육용 문장 174개 중 격식 있는 명령형이 남아 있던 158개를 주세요/마세요 체로 수정했다. source_sha256·실제 원문·AI 응답 전문·역할·순서는 유지한다. 따라 하기의 교육용 요청은 빌드 시 같은 문체로 표시하고 복사하며, 원천 JSON과 원문 다운로드는 바꾸지 않는다. 발표와 과정 본문의 교육용 요청 예시도 동일한 문체로 맞췄다.


## v1.9.2 · AI 응답 경어체 정리

구어체·단답형 AI 응답 43개를 의미와 시제를 유지한 경어체로 편집했습니다. 요약 13개는 완결된 설명 문장으로 풀었으며 원문 전문으로 승격하지 않았습니다. 이미 경어체인 응답과 코드·자료 목록은 유지합니다. 원문 파일은 보존하며 editorial-responses.json의 원문 해시와 확보 수준을 빌드에서 확인합니다. 화면 복사·검색에는 편집 문장을 사용합니다.

2026-10-14 WEBGUI 원본 추가 확보를 시도했으나 제공된 프로젝트 내부 URL은 로그인 화면으로 이동했습니다. 새 AI 전문을 확보했다고 표시하지 않았으며 기존 누락·발췌 구분을 유지합니다. 공개 공유 링크 또는 대화 내보내기 파일을 받으면 원문 대조·전체 반영을 계속해야 합니다.


## v1.10.0 · 네 프로젝트 공유 대화 전문 반영

2026-10-14 제공된 WEBGUI·ERP MCP·Obsidian·에이전트 통신 공유 대화를 화면의 각 요청 위치로 이동하며 확인했습니다. 사용자 요청 56개, 최종 AI 응답 전문 51개, 진행 안내 50개와 본문 없는 상태 2개를 해당 프로젝트의 기존 학습 흐름에 통합했습니다. 포털 전체는 6개 프로젝트·59개 에피소드·407개 항목(원문 전사 402, 본문 없는 안내 5)입니다.

- MCP의 요약 13개·발췌 1개를 실제 전문으로 교체했습니다. Linux 설치, Python·Telegram 코드, 표와 텍스트 구성도를 생략하지 않았습니다.
- WEBGUI 초기 CSS 요청과 전체 분석 요청을 새 단계로 추가했습니다. SYSTEMGUI 수정, 화살표 오류 대응, Chrome v3 진행·최종 결과, 구조 개선 제안을 확보했습니다.
- 기존 사용자·응답 ID를 대응 근거가 있는 경우 유지하고 새 항목은 SHARED ID로 추가했습니다. 기존 진행 안내도 보존하되 최종 응답과 별도 표시합니다. 이전 sources 파일·해시는 변경하지 않았습니다.
- 네 프로젝트에서 확보한 첨부 91개를 연결했습니다. 같은 바이트의 중복 파일은 다운로드 경로를 재사용합니다. 자료 탭에서 보고서·코드·ZIP을 받고, 본문에 이름이 나온 첨부는 말풍선에도 다운로드를 표시합니다.
- 원본 HTML 캡처와 Markdown 전사를 별도로 보존했습니다. 원문·코드·표·텍스트 구성도를 유지하고 화면의 구어체만 입니다/하겠습니다 체로 편집했습니다.
- WEBGUI의 초기 두 응답 위치는 도구 상태 또는 생각 중지됨만 보입니다. 원문이 없는 답변을 생성하지 않았습니다. 공유 화면의 37번 위치는 별도 본문이 보이지 않았고, 교육자료 요청 및 결과 문의는 이후 실제 최종 응답으로 이어집니다.
- 공유 이미지 14개는 업로드 표시만 보입니다. 기존 안전한 Network 이미지 1개를 유지했으며 식별자 때문에 배포 제외된 나머지 화면은 판독 메모와 제외 사유를 유지합니다. Obsidian의 별도 그래프 캡처 2장도 기존 과정에 그대로 있습니다.
- 과거 추출 답변의 미확보 설명은 당시 상태입니다. 새 전문 확보를 서버 설치·ERP 운영·Chrome 실증 또는 제품·SDK 정보의 현재 유효성 검증으로 확대하지 않았습니다.



## v1.10.1 · 진행 안내와 최종 답변

기존 공유 캡처와 전문 데이터를 유지합니다. MCP M008의 구버전 요약 대신 기존에 확보한 전문이 배포되도록 루트 진입점을 dist로 연결합니다. 전체 407개 위치·402개 전사·5개 본문 없는 안내는 동일하며 미확보 본문을 생성하지 않았습니다. 긴 최종 AI 답변은 기본으로 펼치고 실제 진행 안내는 별도의 접힌 항목으로 표시합니다. 다음 대화는 요청에 이어지는 AI 항목까지 포함하여 진행 안내에서 중단되지 않습니다.

카카오 kwc-m004~008은 원문을 보존한 채 게시 메타데이터로 진행 안내임을 표시합니다. kwc-e02에는 같은 요청에 이어지는 kwc-m007~009를 추가 연결하여 최종 결과 전문이 보이도록 했습니다. 기존 kwc-e03 및 발화 ID는 유지합니다.
